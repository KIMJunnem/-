## Astra 기준 원가 가정

GPT-6 Astra의 API 단가는 입력 토큰 100만 개당 $10, 출력 토큰 100만 개당 $50로 계산했다. 검수 1회당 입력 10,000토큰과 출력 2,000토큰을 가정하면 비용은 `$0.10 + $0.10 = $0.20`이다. 실제 문서 길이, 재시도, 컨텍스트 캐시와 모델 선택에 따라 변동한다.

원화 환산은 2026-09-16 한국무역협회가 표시한 USD 기준환율 1,368.40원을 참고해 계산 편의를 위해 1달러=1,370원으로 반올림했다. 토큰 사용량 편차에 대비해 계산 원가에 20%를 더한 보호 원가도 함께 표기한다.

## 3개 공급자 순환 시 예상 토큰비

검수당 입력 10,000토큰·출력 2,000토큰을 똑같이 사용한다고 가정했다. 2026-09-16 공식 단가는 GPT-6 Astra $10/$50, Claude Sonnet 5 $2/$10, Gemini 3.1 Flash-Lite $0.25/$1.50(입력/출력 100만 토큰당)이다.

| 공급자 | 회당 추정 USD | 회당 환산 원가 |
| --- | ---: | ---: |
| OpenAI GPT-6 Astra | $0.2000 | 약 274원 |
| Claude Sonnet 5 | $0.0400 | 약 55원 |
| Gemini 3.1 Flash-Lite | $0.0055 | 약 8원 |

3회(세 공급자 각 1회)는 약 $0.2455·336원, 5회(2·2·1회)는 공급자 배치에 따라 약 $0.2910~$0.4855·398~665원이다. 이 추정은 각 회차가 동일한 토큰을 쓴다는 가정이며, 모델의 실제 이름·긴 사고 출력·재시도에 따라 달라진다. 상품가는 가장 비싼 Astra만 연속 사용해도 토큰비를 감당하는 보수적 상한으로 제안했다.

마진은 판매가에서 보호 원가만 뺀 값이다. 작업자 시간, 부가세, 숨고·결제 수수료, 고객지원, 실패 재실행 비용은 반영하지 않은 **토큰비 전용 추정치**이며 순이익률이 아니다. 문서나 코드가 길어져 검수당 입력 100,000토큰·출력 20,000토큰을 쓰면 Astra 추정 원가는 회당 약 2,740원, 5회 약 13,700원까지 오른다. 따라서 짧은 검수 상품은 입력량 상한 또는 페이지·토큰 구간을 두고, 초과 시 사전 동의를 받는 편이 안전하다.

현재 숨고 의뢰 기본 6회 교차검수와 중복 과금하지 않는다. 위 가격은 별도로 판매하는 추가 검수 상품의 참고 가격이다. 이 상품을 실제 판매 목록에 등록하기 전에는 수수료·세금과 실제 API 사용량을 20~30건 측정해 가격을 다시 조정한다.

## 모델 배정

기본 검수자는 OpenAI·Claude·Gemini가 회수별로 순환한다. 3회는 세 모델 각 1회, 5회는 2·2·1회로 배정하고 첫 검수 모델은 의뢰별 시작점을 바꿔 어느 공급자도 계속 한 번 적게 맡지 않도록 한다. 6회는 각 2회다. 키·쿼터·오류로 한 공급자를 사용할 수 없으면 실제 실행 모델을 기록하고 나머지 사용 가능한 모델로 순환한다. 계획상 비율을 실적처럼 표시하지 않는다.

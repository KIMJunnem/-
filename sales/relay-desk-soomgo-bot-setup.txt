# Relay Desk 숨고 자동 견적 봇

숨고 요청 상세 화면의 `이용 목적·파일 형식·작업 분량·작성 주제·완료 희망일`을 읽어 로컬 Relay Desk 서버에 보냅니다. 서버는 금액·예상 소요일·기본형/확장형/제출형 범위를 계산하고, 확장 프로그램은 숨고 견적 입력창에 내용을 채운 뒤 발송합니다. 고객이 네 가지 조건을 확인하고 최종 고용하기를 누르면 채팅 봇이 그때 `/api/soomgo/hire`를 호출해 Relay Desk 작업을 만들고 AI 실행 큐를 시작합니다. 채팅 화면에서는 고객의 새 메시지를 읽어 가격·소요일·자료 요청 같은 단순 문의에 자동으로 답하고, 결제·환불·범위 변경 문의는 직접 확인 대기로 남깁니다.

## 한 번만 설정

1. Relay Desk 서버를 먼저 실행합니다. `http://127.0.0.1:8787/api/health`가 `ok`여야 합니다.
2. Chrome 또는 Edge에서 `확장 프로그램 관리`를 열고 개발자 모드를 켭니다.
3. 요청 견적 봇 ZIP과 고객 채팅 봇 ZIP을 각각 압축 해제한 뒤, `압축해제된 확장 프로그램을 로드`로 두 폴더를 각각 등록합니다. 요청 봇은 `받은 요청`, 채팅 봇은 `pro/chats` 화면에서만 실행됩니다.
   코드가 업데이트된 뒤에는 확장 프로그램 관리 화면에서 Relay Desk 숨고 자동 견적 카드의 `새로고침` 아이콘을 한 번 눌러 최신 버전을 적용합니다.
4. 같은 브라우저에서 숨고 고수 계정으로 로그인합니다. 로그인 세션은 이 브라우저 프로필에 저장됩니다.
5. 숨고의 `받은 요청` 화면과 별도 `고객 채팅` 창을 열어 둡니다. 요청 봇은 목록을 확인하고 새 요청을 열어 견적을 작성·발송하며, 채팅 봇은 새 메시지에 답합니다. 두 패널의 `전체 정지`를 누르면 두 봇을 함께 멈출 수 있습니다.

기본값은 견적 자동 발송과 단순 채팅 자동 답변입니다. 패널의 `ON`을 눌러 즉시 일시 정지할 수 있고, 고객 채팅방의 `현재 대화 수동 관리`로 특정 고객만 자동 답변에서 제외할 수 있습니다. `전체 정지`는 두 봇을 동시에 멈춥니다. 직접 대면·방문·출장·현장 작업·오프라인 진행·화상회의가 명시된 요청과 대본·시나리오·각본·스크립트·콘티 의뢰는 자동으로 제외하고, 온라인·비대면·원격 일반 문서 요청은 접수합니다. 받은 요청 목록은 30초마다 확인합니다. 자동 견적은 내부 기준가 가설을 계산합니다. 외부 평균가는 출처·조사일 확인 전까지 확정값으로 주장하지 않습니다. 30,000원 미만은 기준가에서 오픈 기념 30%, 30,000원 이상도 기준가에서 오픈 기념 30%를 적용해 금액 입력란에 넣고, 견적 내용에는 `【견적 금액】`, `【최종 제안가】`, 예상 소요일·기본 포함 범위·추가금 발생 기준을 줄바꿈으로 표시한 뒤 발송합니다. 샘플은 최종 판매가의 25%이며 본 작업으로 전환하면 샘플비를 전액 차감합니다. 발송 결과를 확인할 수 없으면 중복 발송하지 않고 수동 검토로 남기며, 실제 결과와 발송 시각을 활동 기록에 저장합니다. 기본형·확장형·제출형별 페이지·자료조사·표/이미지·수정 범위를 안내하고, 페이지·소주제·자료조사·표/이미지·수정 횟수가 기본 범위를 넘거나 긴급 납기이면 추가금 조건을 표시합니다. 제외된 요청은 숨고에 견적을 보내지 않고 패널에 표시하며, 서비스 항목 자체는 삭제하지 않습니다. 자동 답변은 실제 채팅방에서만 대화 입력창과 전송 버튼을 확인한 뒤 대화당 새 메시지를 한 번 처리하고 24시간 20건으로 제한합니다. 가격·납기·시작일·자료·진행 절차·파일 형식·페이지·수정 횟수·자료조사·표/이미지·요약·문체·샘플·보안·원격 진행·언어·납품·연락 방법·가능 여부 등 유형별 안내 문구를 사용하고, 문의 메시지에 따라 20개 마무리 문구를 조합해 수백 가지 표현을 만듭니다. 고객의 최종 고용 승인이 확인되면 Relay Desk 작업을 생성하고 AI 실행 큐를 시작합니다. 고용 확정 직후에는 감사 인사와 예상 소요일·1차본 안내를 한 번 보내고, 이후에는 고객의 현재 질문에만 답합니다. 총액 50,000원 초과는 착수금·잔금으로 나눌 수 있고 각 거래는 15,000원 이상입니다. 착수금 결제 후 초안을 만들고 기존 거래가 확정되면 채팅방의 `이어서 거래하기`로 잔금을 요청합니다. 50,000원 이하·긴급 작업은 전액 선결제입니다. 자료 확인 뒤 범위가 늘면 작업을 멈추고 사유·추가금을 한 번 안내하며 고객 동의 전에는 진행하지 않습니다. 숨고페이 결제 후 금액은 수정할 수 없으므로 기존 범위까지만 완료·거래확정한 뒤 `이어서 거래하기`로 추가 거래를 요청합니다. 결제·환불·범위 변경·긴급 일정·과제·대본/시나리오 문의는 수동 검토로 남깁니다. 같은 요청 ID는 한 번만 처리합니다.

목록을 새로고침하는 주기는 `content.js`의 `refreshMs` 기본값(30,000ms)으로 정해져 있습니다. 견적 발송 후에는 상단 `요청·견적` 메뉴로 돌아가 목록을 한 번 새로고침합니다. 발송 결과가 확인되지 않은 건은 중복 발송하지 않고 수동 확인으로 남깁니다. 견적 접수 이벤트는 큐로 전달되어 채팅 봇이 건별로 한 번씩 새로고침합니다. 확장 프로그램 업데이트 후에는 Chrome 확장 프로그램 관리 화면에서 해당 카드의 새로고침 아이콘을 눌러 최신 발행본을 적용해야 합니다.

## 첫 테스트

처음에는 테스트 요청 한 건으로 확인합니다. 입력창에 금액·소요일·설명만 채워지고 발송 버튼이 보이지 않으면 숨고 화면을 한 번 더 열어 주세요. 버튼 문구가 계정/화면에 따라 다르면 `content.js`의 `findSendButton` 후보를 해당 문구에 맞춰 추가하면 됩니다.

릴레이 서버에는 분석된 요청이 `server/data/state.json`의 `soomgoLeads`와 활동 기록으로 남습니다. API 키는 확장 프로그램에 저장하지 않습니다.

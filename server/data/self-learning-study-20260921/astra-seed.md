# Relay Desk 반복 연구 핵심 교본

## 0. 목적과 기록 원칙
일반 문서·교정·타이핑·한국어 SRT 자막을 **약속한 범위와 품질로 납품**한다. 연구의 목적은 그럴듯한 설명이 아니라 재현 가능한 운영 개선이다.
- 모든 기록에 **[사실] [가설] [제안]**을 붙인다. 사실에는 출처·날짜·표본 수·적용 범위를, 가설에는 반증 조건을, 제안에는 비용·위험·검증 방법을 적는다.
- “작성함→내부 검수함→발송함→고객 확인함”을 구분한다. 초안 생성은 발송이나 승인 완료가 아니다. 확인할 수 없는 값은 추정으로 표시한다.

## 1. 근거 중심 사고
근거는 주문·작업 로그, 고객 원문, 공식 규격, 재현 실험 순으로 목적에 맞게 평가한다. 후기·경쟁사 문구는 탐색 자료이지 효과의 증명이 아니다. 링크뿐 아니라 핵심 인용과 수집일을 남긴다.
- 평균만 보고하지 말고 건수·중앙값·범위·실패 사례를 함께 기록한다.
- 소수 고객의 반응은 “관찰된 신호”로 표현한다. 응답 없는 고객을 만족 고객으로 세지 않는다.
- 반대 증거를 최소 한 번 찾는다. 출처 불명·조건 불일치·재현 실패 시 결론을 보류한다.

## 2. 고객 응대
첫 응답에서 서비스 종류, 원본 상태·분량, 사용 목적, 납기, 출력 형식, 참고 양식, 개인정보 포함 여부를 확인한다. 빠진 정보는 견적·납기에 미치는 영향이 큰 것부터 묻는다.
- 요청을 짧게 재진술하고 **포함/제외 범위·금액·납기·수정 조건**을 서면 확인한다.
- 불명확한 지시를 임의로 확대하지 않는다. 추가 작업은 변경 견적 승인 후 진행한다.
- 오류가 나면 영향·현재 상태·복구안·다음 안내 시점을 알린다. 확인 전 환불·완료·발송을 단정하지 않는다.

## 3. 가격과 범위
서비스별 과금 단위와 계산 기준을 고정한다. 문서·교정은 글자 수 또는 쪽수, 타이핑은 원본 분량과 판독 난도, SRT는 영상 길이와 음질·화자 수·싱크 작업 여부로 산정한다. 쪽수는 서식 기준도 명시한다.
- 가격 하한은 **예상 노동비+검수비+도구비+재작업 충당액**으로 계산한다. 시장가는 참고값이며 확정 요금은 별도 가격표에서 관리한다.
- 교정과 재작성, 타이핑과 내용 보완, 자막 전사와 번역을 분리한다.
- 납품 오류 수정과 고객의 새 요구를 구별한다. 할인 실험도 수익 하한과 수용량을 넘으면 중단한다.

## 4. 자동화 안전
원본은 읽기 전용으로 보존하고 사본에서 작업한다. 고객 데이터는 최소한만 수집하며 접근권한·보관기간·삭제 방식을 정한다. 외부 도구 업로드는 고객 동의와 도구의 데이터 처리 조건을 확인한 뒤 시행한다.
- 자동화는 초안·탐지·형식 검사부터 적용한다. 발송·결제·덮어쓰기·삭제는 승인 절차를 둔다.
- 실행 전 시험 모드, 실행 후 변경 비교·로그·복구 경로를 확인한다.
- 판독 불가·음성 불명·도구 오류는 추측으로 메우지 말고 표시해 검토한다. 검사 실패 시 자동 납품을 차단한다.

## 5. 실험 설계
매회 질문 하나, 주지표 하나를 정한다. 예: “용어표가 자막 고유명사 오류를 줄이는가?” 대조 조건, 작업 유형, 표본 선정, 관찰 기간, 최소 개선폭, 중단 기준을 실행 전에 기록한다.
- 속도 실험도 오류율·재작업 시간·고객 불만을 안전지표로 둔다.
- 가능한 경우 같은 난도의 자료를 무작위 배정하고 평가자는 작업 방식을 모르게 한다.

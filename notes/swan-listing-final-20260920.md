# Swan 판매 문구 최종안

## 숨고 질문답변

### 서비스 시작 절차
숨고 채팅으로 문서 용도 또는 영상 길이, 자료, 원하는 파일 형식과 마감일을 확인합니다. 범위와 총액, 착수 가능일을 먼저 안내하고 결제가 확인되면 작업을 시작합니다. 1차본 확인 뒤 합의한 범위에서 수정 1회를 반영합니다.

### 전문 서비스
일반 문서 작성과 한국어 SRT 자막 제작을 합니다. 일반 문서는 제공 자료를 바탕으로 1,500자 이하를 정리하고, 자막은 한국어 영상 5분 이하의 발화 타이밍에 맞춘 SRT 파일 1개를 제작합니다. 자기소개서·이력서, 번역, 영상 편집과 자막 삽입은 접수하지 않습니다.

### 견적 산정
일반 문서는 1,500자 이하 21,000원, 한국어 SRT 자막은 영상 5분 이하 32,000원입니다. 분량이 늘거나 자료 상태와 마감 조건이 달라지면 작업 전에 범위와 금액을 다시 안내합니다.

### 대표 작업
일반 문서는 전달받은 자료를 목적에 맞게 읽기 쉬운 문서로 정리합니다. 한국어 SRT 자막은 영상의 실제 발화 시점을 확인해 타임코드와 문장을 맞춥니다. 자료 확인 후 2영업일 이내 납품을 기본으로 합니다.

### 수정·환불
합의한 범위 안의 오탈자, 누락, 문장 흐름 또는 타임코드 보완은 수정 1회에 포함됩니다. 신규 내용 추가와 분량 확대는 별도 범위입니다. 환불은 실제 진행 분량과 플랫폼 결제 상태를 확인해 각 플랫폼 정책에 따라 처리합니다.

## 크몽 일반 문서 상품

### 서비스 설명
보내주신 자료를 읽고 목적에 맞는 일반 문서로 정리합니다. 안내문, 소개문, 요약문, 보고용 글처럼 이미 가지고 계신 내용을 읽기 좋은 문장과 구조로 다듬어 드립니다.

기본 상품은 1,500자 이하 일반 문서 1건이며 가격은 21,000원입니다. DOCX 또는 PDF 중 1종, 합의한 범위 안의 수정 1회를 포함합니다. 자료 확인 후 2영업일 이내 납품을 기본으로 합니다.

자기소개서·이력서 작성과 첨삭, 전문 자격이 필요한 법률·의료 문서, 사실 확인이 어려운 내용은 접수하지 않습니다. 자료조사, 신규 내용 추가, 분량 확대가 필요한 경우에는 결제 전에 가능 여부와 범위를 먼저 안내합니다.

완성된 결과물의 저작권은 최종 결제 후 의뢰인에게 귀속됩니다. 의뢰인은 결과물을 상업적으로 이용할 수 있습니다. 제작 이미지에는 Windows 기본 글꼴인 맑은 고딕을 사용하며 별도 유료 폰트를 사용하지 않습니다.

### 서비스 제공 절차
1. 문서 용도, 분량, 참고 자료, 원하는 파일 형식과 마감일을 확인합니다.
2. 접수 범위와 착수 가능일을 안내합니다.
3. 결제와 자료가 확인되면 작업을 시작합니다.
4. 1차본을 전달하고 합의한 범위 안에서 수정 1회를 반영합니다.
5. DOCX 또는 PDF 중 합의한 형식으로 최종본을 전달합니다.

### 패키지
- STANDARD: 1,500자 이하, 21,000원, 2일, 수정 1회
- DELUXE: 3,000자 이하, 42,000원, 3일, 수정 1회
- PREMIUM: 4,500자 이하, 63,000원, 4일, 수정 1회

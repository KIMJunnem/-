# 작업기록 — 유튜브·브이로그 편집 샘플 (2026-09-25, 클라우드 세션)

## 결과
- 파일: `swan-youtube-sample.mp4` — 66.9초, 1920x1080 16:9, 30fps, H.264 + AAC 160k, 19.25MB
- 구성: 훅 카드(원본 vs 편집본, 2.8초) → **원본 그대로 12.2초** → "편집본" 카드 → **편집본 35.1초** → 숫자 카드(38.3초 → 35.5초) → **원본|편집본 나란히 6.6초** → 끝 화면
- 소재: 말하는 영상 1(CC BY 3.0) + B롤 영상 1(CC BY 4.0) + B롤 사진 3(CC0) + 음악 1(CC BY 3.0) + 글꼴 2(OFL). 출처는 `출처-라이선스.md`.

## 스타일표(youtube 행)대로 한 것
- 전후 비교: Commons에서 영어 자막이 달린 CC 말하는 영상을 찾아 씀. 같은 말(원본 76~88초)을 원본으로 먼저 보여 주고, 편집본과 나란히 한 번 더 보여 줌.
- 쉼 잘라내기: 소리 분석(-30dB, 0.15초 이상)으로 쉼 16곳을 찾아 그중 14곳을 앞뒤 0.06초만 남기고 잘라냄 → 38.3초가 35.5초.
- 줌: 잘린 토막마다 100%↔108% 번갈아(점프컷).
- B롤: 4컷(미술관 위에서 본 사진, 바티칸 지도 회랑 영상, 도서관, 박물관 홀). 목소리는 이어지고 화면만 바뀌는 L컷. 편집본 시작은 목소리가 0.4초 먼저 들어오는 J컷.
- 자막: 굵은 고딕(Black Han Sans) + 두꺼운 검정 외곽선, 핵심 낱말만 노란색·1.25배. 11개. 효과 글자 1번("보고 / 나누고 / 다시 쓰게"가 차례로 튀어나옴, 얼굴을 가리지 않게 오른쪽).
- 색: 피부 톤 보정(밝기 +0.025, 대비 1.04, 채도 1.06, 붉은/노란 쪽으로 살짝).
- 음악: Antti Luode "Chill Beat"(가벼운 비트). 사이드체인으로 말할 때 자동으로 줄임 — 말하는 구간 음악 레벨이 음악만 나오는 구간보다 약 17dB 낮음(측정: -22.3 → -39.5 dBFS). 원본 구간(편집 전)에서는 음악을 끔.
- 전환: 컷, 점프컷(줌), J/L컷 겹치기 없음 — 화려한 전환 없음. 웨딩 샘플(얇은 세리프·크림/금색·느린 겹침)과 글꼴·색·자막 모양·전환이 겹치지 않음.

## 쓴 스킬
- `anthropic-skills:canvas-design` — 디자인 철학 "Punch Type"을 정하고 자막 11개·칩·훅/전환/숫자/끝 화면 카드·효과 글자 프레임을 코드(Pillow)로 그림. 한글 외곽선이 깨지는 문제를 글자 마스크 팽창 방식으로 고침.
- `anthropic-skills:algorithmic-art` — 철학 "Signal Rush"(시드 고정 흐름장 입자, 속도에 따라 회색→노랑, 3%만 산호색)를 정하고, 영상에 넣기 위해 p5.js 대신 같은 방식을 Python으로 옮겨 300프레임 모션 배경을 렌더(훅·전환·숫자·끝 화면 배경). 스킬의 HTML 뷰어는 만들지 않음(영상 프레임이 목적이라).
- 편집·검사는 ffmpeg 7.0.2(imageio-ffmpeg) + Python 스크립트.

## 기준 못 맞춘 것 (수치 그대로)
- **컷의 70% 박자 맞춤: 55%(22컷 중 12컷)로 미달.** 음악에서 고른 컷(구간 전환·B롤 들어가고 나가는 곳) 13곳 중 12곳은 박자 ±2프레임 안(박자는 자동 분석 추정값 64 BPM, [추정]). 나머지 9곳은 말의 쉼에 맞춰 자른 점프컷이라 박자에 맞출 수 없음. 점프컷을 박자에 맞추면 말이 잘려서 그대로 둠.
- **"음·어" 잘라내기는 못 함.** 음성 인식 도구가 없어 말버릇 낱말은 찾지 못했고, 소리 크기로 찾은 쉼·숨 구간만 잘랐음. 원본이 이미 다듬어진 영상이라 줄어든 길이가 2.8초(7%)로 작음.
- 자막-말 싱크 중앙값 0.1초: 낱말 단위 시간 정보가 없어 정밀 측정 못 함. 자막 시작을 쉼이 끝나는 지점(말 시작)에 맞췄음([추정] 0.1~0.3초 안).
- 원본 영상 해상도가 1280x720이라 1080으로 키움(108% 줌 구간은 조금 더 부드러움).
- 사람이 직접 보고 듣는 확인은 못 함. 준희 확인 필요: 샘플 보고 ㅇ → 유튜브 일부공개 → 링크를 클라우드 세션에 전달.

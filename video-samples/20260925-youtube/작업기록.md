## 결과

## 스타일표(youtube 행)대로 한 것
- 전후 비교: Commons에서 영어 자막이 달린 CC 말하는 영상을 찾아 씀. 같은 말(원본 76~88초)을 원본으로 먼저 보여 주고, 편집본과 나란히 한 번 더 보여 줌.

- 줌: 잘린 토막마다 100%↔108% 번갈아(점프컷).
- B롤: 4컷(미술관 위에서 본 사진, 바티칸 지도 회랑 영상, 도서관, 박물관 홀). 목소리는 이어지고 화면만 바뀌는 L컷. 편집본 시작은 목소리가 0.4초 먼저 들어오는 J컷.
- 자막: 굵은 고딕(Black Han Sans) + 두꺼운 검정 외곽선, 핵심 낱말만 노란색·1.25배. 11개. 효과 글자 1번("보고 / 나누고 / 다시 쓰게"가 차례로 튀어나옴, 얼굴을 가리지 않게 오른쪽).
- 색: 피부 톤 보정(밝기 +0.025, 대비 1.04, 채도 1.06, 붉은/노란 쪽으로 살짝).
- 음악: Antti Luode "Chill Beat"(가벼운 비트). 사이드체인으로 말할 때 자동으로 줄임 — 말하는 구간 음악 레벨이 음악만 나오는 구간보다 약 17dB 낮음(측정: -22.3 → -39.5 dBFS). 원본 구간(편집 전)에서는 음악을 끔.
- 전환: 컷, 점프컷(줌), J/L컷 겹치기 없음 — 화려한 전환 없음. 웨딩 샘플(얇은 세리프·크림/금색·느린 겹침)과 글꼴·색·자막 모양·전환이 겹치지 않음.

# v2 — 색감·글꼴 수정본 (2026-09-25, 클라우드 세션)

준희 피드백: ① "색감이 더 구려졌다" ② "폰트도 오히려 깔끔한 게 나을 듯, 너무 튀어". 둘 다 고친 v2. 1차본 파일은 그대로 둠.

## 결과
- 파일: `swan-youtube-sample-v2.mp4` — 65.97초, 1920x1080 16:9, 30fps, H.264(2-pass 2080k) + AAC 160k, 18.75MB
- `grade-compare-v2.jpg` — 같은 프레임 3장(원본 64.0/83.0/97.3초) 보정 전|후
- `contact-sheet-v2.jpg` — 균등 6프레임(5.5/16.5/27.5/38.5/49.5/60.5초)
- 구성·자막 문구는 1차본과 같음: 훅 카드 2.8초 → 원본 그대로 12.2초 → "편집본" 카드 → 편집본 → 숫자 카드 → 원본|편집본 나란히 6.6초 → 끝 화면

## 1. 색감
- 1차본 문제: 원본 웹캠 영상이 원래 주황·어두운데, 1차본은 여기에 붉은/노란 쪽을 더 얹어 탁해짐.
- v2 보정(ffmpeg, 순서대로):
  - `hqdn3d=1.2:1.2:2.5:2.5` (약한 잡티 제거, 720p 단계)
  - 채널별 곡선 `curves` — R `0/0 0.05/0.03 0.39/0.53 0.91/0.93 1/0.98`, G `0/0 0.05/0.035 0.384/0.53 0.537/0.72 1/1`, B `0/0 0.05/0.04 0.345/0.53 0.388/0.575 0.7/0.85 1/1` (회색 배경을 회색으로 맞추고 중간톤 올림, 얼굴 빨강 줄임)
  - `eq=contrast=1.05:saturation=0.97`
  - `scale=1920:1080:flags=lanczos`, `unsharp=5:5:0.45:5:5:0` (약하게)
- 측정(보정 전 → 후, 0~255): 배경 회색 R/G/B 90/90/79 → 117/121/115 (노란기 제거, 중립), 화면 평균 밝기(luma) 82 → 103, 얼굴 약 R235 G184 B142(살구색). 흰 이어폰 줄은 흰색으로 보임.
- 시행착오: colorbalance/eq 조합은 배경이 청록으로 가서(G가 R보다 +11) 버리고 채널별 곡선으로 바꿈. 비교 이미지를 직접 보고 탁하지 않음을 확인. [추정] 배경에 아주 약한 초록기(G +4) 남음.
- B롤: `eq=gamma=1.04:contrast=1.03:saturation=0.94`로 같은 깨끗한 톤만 살짝. 자막·카드는 보정 뒤에 얹음.
- '원본 그대로' 구간과 나란히 비교의 왼쪽은 보정 없이(lanczos 확대만) — 전후 차이가 보이게.
- 소재 교체: 안 함. 원본이 1280x720 웹캠 영상이라 한계는 있지만 보정 후 밝기·색이 기준에 맞았고, Wikimedia가 이 세션 IP에 요청 제한(429)을 걸어 새 소재 검색·다운로드가 어려웠음.

## 2. 자막·글꼴
- 글꼴: Black Han Sans → **Pretendard** SemiBold(기본)·Bold(강조)·Medium/Regular(보조). 저장소 `services/presentation-design/fonts`의 OFL 파일 사용.
- 자막: 흰 글자 50px + 반투명 먹색 둥근 바탕(투명도 46%, 모서리 18px) + 은은한 그림자(블러 5px, 55%). 두꺼운 외곽선 없앰.
- 강조: 핵심 낱말만 채도 낮은 민트(#96D6C2) + Bold. 크기 키우기(1.25배) 없앰. 자막은 4프레임 페이드 인·3프레임 페이드 아웃, 튀어나옴 없음.
- 효과 글자 "보고 / 나누고 / 다시 쓰게": 64px, 7프레임 페이드 + 10px 떠오름만(튀어나옴 없앰), "다시 쓰게"만 민트.
- 칩("원본 · 편집 전", "편집본", "원본"), 훅·전환·숫자·끝 화면 카드 모두 같은 글꼴·흰색/회색/민트 3색으로 통일. 칩은 90% 안전 영역 안(96,60).
- 입자 배경: 노랑·산호색 → 먹색 바탕(#14181D) + 회청색 선, 민트 2%, 밝기 절반 수준으로 은은하게.
- 웨딩 샘플(고운바탕 세리프, 크림·금색, 느린 겹침)과 다름: 고딕·먹색/흰색/민트·컷 편집.

## 컷 박자 맞춤: 55% → 93%
- 음악 박자 자동 분석: 64 BPM(0.9375초), [추정].
- 쉼(-30dB·0.15초 이상)을 새로 분석(47곳). 그중 0.25초 이상인 쉼만 후보로 하고, 각 쉼에서 남기는 길이(최소 0.06초씩)를 조절해 컷이 박자에 떨어지게 함. 말은 자르지 않음(쉼 안에서만 자름).
  - 0.45초 이상 긴 쉼은 박자에 못 맞춰도 자름(1곳), 짧은 쉼은 박자에 맞을 때만 자름.
  - 남기는 쉼은 최대 0.35초까지만 허용(더 남기면 쉼 정리 효과가 없어져서).
- 결과: 쉼 10곳 정리, 38.0초 → 34.2초(-3.9초, 1차본은 -2.8초).
- 화면에서 보이는 컷 15개 중 14개가 박자 ±2프레임 안(93%). 못 맞춘 1개는 37.0초 점프컷(13프레임 어긋남, 1초짜리 긴 쉼). B롤에 가려 화면에 안 보이는 점프컷 3개는 셈에서 뺌.
- B롤 4컷도 박자 위치에서 들어가고 나감. 편집본 시작은 1차본처럼 목소리 0.4초 먼저(J컷).

## 로고 가리기 (1차본 문제도 같이 고침)
- 원본 로고 구간을 프레임 비교로 다시 잼: 68.35초에 나타나 76.37초에 완전히 사라짐(디졸브), 그리고 영상 끝 99.1초부터 로고가 다시 나옴.
- 1차본은 76.0초까지만 가려서 이음매 1~2프레임에 로고가 비쳤고, 끝(51.5초 부근)에도 "VOICES"가 희미하게 보였음.
- v2: 바티칸 B롤을 소스 76.45초까지, 마지막 B롤(빅토리아풍 박물관)을 편집본 끝 2박(48.76~50.63초)으로 옮겨 끝 로고도 가림. '원본 그대로' 구간은 76.4초부터(소리만 0.11초 먼저).
- 확인: 계획표로 로고 구간 프레임이 화면에 나오는 곳 0개, 출력 전체 프레임을 로고 프레임과 비교해 유사도 최대 0.21(로고 없음).

  - B롤: 사진 3장은 프레임마다 확대·이동 값을 맞춰 복원(일치도 0.99 이상), 바티칸 영상은 35.0초부터 1:1.
  - 자막 11개·효과 글자 3개·칩 시간은 v2 프레임에서 켜지고 꺼지는 지점을 재서 복원.
- 원본에서 v3 색으로 다시 그리고 자막·칩·효과 글자를 새로 얹음. 훅 카드·'원본 그대로' 구간·"편집본" 카드·숫자 카드·끝 화면은 v2 프레임을 그대로 씀(색 보정과 무관한 구간).
- 나란히 비교 구간은 오른쪽(편집본) 칸만 v3 색으로 바꿈. 왼쪽(원본)은 보정 없음 그대로.

## 스타일표(lecture 행)대로 한 것
- 긴 말 정리: 10분 26초 인터뷰에서 주제 하나(홍수·기후·예보)로 3개 장을 뽑음. 장마다 끝에 요약 카드 한 장(긴 말 → 두 줄 문장).
- 말 끊김 정리: 2장에서 모델 설명 약 10초를 덜어내고 이음매를 자료 화면으로 덮음(목소리는 이어짐). 3장에서 말버릇 "you know" 1곳을 잘라내고 106% 확대로 이음매를 자연스럽게 함. 잘라낸 자리는 소리 크기(-40dB 아래 쉼)를 보고 골랐고 가장자리 12ms 페이드.
- 자막: Noto Sans KR Medium 46px 흰 글자 + 반투명 남색 상자(외곽선 없음), 화면 아래 가운데. 영어 음성을 한국어로 요약 번역, 13개.
- 챕터 제목: 장이 시작될 때 흰 카드("n / 3" + 장 제목 + 3칸 진행 바)가 3초 뜬 뒤, 왼쪽 위 작은 표시로 줄어 장 끝까지 남음.
- 자료 화면: 2장 첫 4.4초에 도표 슬라이드("지구 시스템 모델이 내다보는 시간", 오늘→1주→2~3주 막대가 채워짐)를 끼워 넣음.
- 색: 어두운 스튜디오 원본을 밝게·중립으로(감마 1.22, 대비 1.08, 채도 0.98, 빨강 살짝 줄임). 흰 티셔츠 기준 RGB 217/213/213 → 보정 후 237/236/232(중립 유지). 주황·탁한 톤 없음, 완전 흰색 화소 0.1%.
- 화면 바뀜 최소: 전환은 0.3초 겹침(디졸브) 한 가지 + 끝 화면 페이드아웃. 요약 카드·도표는 흰·연회색 바탕에 남색 글자, 포인트는 차분한 초록 한 색.
- 배경음: 외부 음악 대신 아주 잔잔한 화음 패드(D·A·D·E·F#, 사인파)를 코드로 만들어 카드 구간에만 들리게, 말할 때 18dB 자동으로 줄임(덕킹).
- 다른 샘플과 겹침 없음: 웨딩(고운바탕 세리프·크림/금색), 유튜브(검은고딕 굵은 외곽선·노랑 강조)와 글꼴·색·자막 모양이 다름.

## 상징 모션과 의미
1. **흩어진 낱말 조각 → 한 문장 요약 카드** (요약 카드 3장 모두): 인터뷰에서 나온 영어 낱말 조각들("more likely", "frequent", "weeks ahead" …)이 흐름을 타고 흩어져 떠다니다가, 수천 개의 점으로 풀려 한국어 요약 문장 모양으로 모이고 또렷한 글자가 됨. 의미: **복잡하고 긴 말이 명료한 한 문장으로 정리된다** — 이 서비스가 하는 일 그 자체.
2. **손으로 긋는 밑줄 · 선으로 그려지는 체크와 전구**: 요약 문장의 핵심 낱말("더 자주, 더 세게", "2~3주 앞까지", "대비합니다") 아래 초록 밑줄이 펜 압력처럼 그어지고, 정리 카드에서 전구와 체크 3개가 한 획씩 그려짐. 의미: **여기가 핵심이고, 이제 이해됐다**는 확인 표시.
- (보조) 챕터 진행 바가 "0/3 → 1/3 → 2/3 → 3/3"으로 채워짐: 지금 어디쯤인지 알려 주는 길잡이.

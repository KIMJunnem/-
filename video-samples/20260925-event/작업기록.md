# 작업기록 — 행사·기업 편집 샘플 (2026-09-25, 클라우드 세션)

## 결과
- 파일: `swan-event-sample.mp4` — 49.5초, 1920x1080 16:9, 30fps, H.264(2-pass 2.75Mbps) + AAC 160k, 18.0MB
- 구성: 행사명 타이틀 모션(0~6초) → 현장 스케치(6~23.5초) → 인터뷰 한마디(23.5~31초) → 스케치 2(31~39.5초) → 숫자 카운터(39.5~44초) → 끝 화면(44~49.5초)
- 소재: 행사 영상 8개(CC BY-SA 4.0) + 인터뷰 영상 1개(CC BY 4.0) + 음악 1곡(CC BY 4.0) + 글꼴 1종(SUIT, OFL). 출처는 `출처-라이선스.md`.

## 스타일표(event 행)대로 한 것
- 컷: 음악 120 BPM(자체 분석, 첫 박 0.464초 [추정]) → 음악을 8.964초부터 써서 박이 영상 0.5초 격자에 오게 맞춤. **컷 18곳 모두 박자 위(100%, 계산상 0프레임 오차)**. 넓은 샷(홀 전체·무대)→가까운 샷(객석·패널·사람)을 번갈아 배치.
- 슬로 모션 2컷: 박수 치는 참가자(0.5배, 13~15.5초), 단체 사진(0.6배, 31~33초). ffmpeg minterpolate로 중간 프레임을 만들어 끊김 없이.
- 인터뷰 한마디: CC 인터뷰 영상(영어)의 7.5초. 얼굴 컷 뒤로 목소리가 이어지며 네트워킹 장면이 나옴(원본 자체의 L컷). 한국어 자막 2개(Commons 영어 자막을 줄여 옮김):
  - "늘 배우는 자세로 살고 싶어요" / "새로운 것도, 새로운 사람도 · 알아 가면서요"
- 하단 자막 바: "○○○ · ○○팀 / 행사 참가자 인터뷰" — 반투명 네이비 바 + 왼쪽 청록 세로줄, 0.45초에 왼쪽에서 밀려 나오고 글자가 따라 들어옴.
- 행사명 타이틀: "20○○ ○○ 컨퍼런스" + "행사 하이라이트". 장면 이름표 "현장 스케치"(왼쪽 위 작은 칩).
- 음악: Rafael Krux "Inspiring Advertising - Upbeat Summer Corporate"(경쾌한 기업 홍보 음악). 인터뷰 동안 0.3초 램프로 -18dB 줄임(덕킹). 목소리는 +4dB 올려 음악 구간과 비슷하게(평균 -17.9 vs -15.5dB).
- 색(준희 피드백 ①): 컷마다 중간톤 회색 기준 화이트밸런스 70% 중립화 → 노출 +6% → 부드러운 S커브 대비 → 채도 +6%. 호텔 조명의 누런 기가 빠지고 흰 의자·천장이 흰색으로 보이게. 인터뷰 영상은 이미 보정된 원본이라 30%만.
- 자막·글꼴(준희 피드백 ②): SUIT 한 가족만, 외곽선 없음. 인터뷰 자막은 상자 없이 화면 아래 옅은 네이비 그라데이션 + 부드러운 그림자. 크기 튀기기 없음.
- 색 구성: 흰색·네이비(#0E1B36)·포인트 청록(#00B2C4) 한 색.
- 전환 3종류 이하: 박자 컷, 타이틀→첫 컷 0.5초 겹침, 끝 화면 페이드아웃.
- 가려낸 것: 패널 무대 화면에 실존 인물 이름이 읽혀 그 부분이 안 보이게 1.7배 확대로 잘라냄. 단체 사진 컷의 큰 행사 현수막은 1.6배 확대로 화면 밖으로. 과자 상표가 보이는 컷, 로고 화면(인터뷰 원본 첫 부분)은 쓰지 않음.

## 상징 모션 (준희 피드백 ③)
1. **흩어진 점들이 선으로 이어져 행사명이 됨(0~6초)** — 점 620개가 제각각 떠다니다 가까워지면 청록 선으로 이어지고(선은 천천히 사라지며 "만난 기억"을 남김), 점점 행사명 글자 자리로 모여 글자가 되고, 마지막에 실제 글자가 떠오름. 의미: **"따로 온 사람들이 서로 이어져 하나의 행사가 된다."**
2. **숫자 카운터(39.5~44초)** — 참석 0→1,200명, 세션 0→24개가 자리마다 조금씩 늦게 올라가 멈춤. 의미: **"한 사람, 한 세션이 모여 행사의 규모가 된다."** (숫자는 예시 자리. 고객 행사 숫자로 바꿔 넣는 부분)
- 끝 화면 배경에도 1번의 네트워크 점·선을 옅게 깔아 처음과 끝을 이음.

## 진행 중 문제
- Wikimedia 원본 파일 서버가 약 1시간 동안 429(속도 제한)를 돌려줌. Pexels·Pixabay는 403. 원본 경로는 끝까지 막혀 있었고, Commons 공식 변환본(transcoded) 경로가 열린 뒤 그것으로 받음(같은 파일, 1080p).

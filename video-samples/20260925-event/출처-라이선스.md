# 출처·라이선스 — 행사·기업 편집 샘플

라이선스는 Wikimedia Commons API(imageinfo extmetadata)로 확인했습니다. CC BY / CC BY-SA만 썼고 NC·ND·불명 소재는 없습니다.
화면에 사람 이름은 넣지 않았습니다("○○○ · ○○팀" 자리 표시만). AI 생성 이미지·영상·합성 음성은 쓰지 않았습니다.
원본 파일 서버가 속도 제한(429)에 걸려, 같은 파일의 Commons 공식 변환본(transcoded, 1080p VP9 / 음악은 Ogg)을 받아 썼습니다. 내용은 같은 파일입니다.

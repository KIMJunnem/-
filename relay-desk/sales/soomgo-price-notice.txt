[가격 및 기본 범위]
아래 금액은 기본 범위 기준 원가와 할인가입니다. 자료량·난이도·추가 요청이 기본 범위를 넘으면 작업 전에 추가 범위와 금액을 안내하고 동의 후 진행합니다.

1. 이력서·자소서 대필: 원가 40,000원 → 할인가 31,000원
2,000자 이내·지원 회사 1곳·고객이 제공한 실제 경험 기반 작성가입니다. 

2. 문서·글 작성: 원가 24,000원 → 할인가 21,000원
제공 자료 기반 1,500자 이내·수정 1회입니다.

3. 교정·교열: 원가 28,000원 → 할인가 22,000원
한글 3,000자 이내 맞춤법·문장 흐름·변경 내역 정리입니다.

4. 속기·타이핑: 원가 24,000원 → 할인가 19,000원
인쇄물 5쪽 또는 명료한 음성 10분 이내를 Word로 변환·대조합니다.

5. 영어 번역: 원가 32,000원 → 할인가 26,000원
일반 영문 300단어 이내·용어 통일·수정 1회입니다.

6. 통계분석: 원가 80,000원 → 할인가 64,000원
정리된 데이터 1개·단순 분석 1종·결과표와 요약 해석입니다.

7. 사업계획서 작성: 원가 160,000원 → 할인가 128,000원
고객 자료 기반 5쪽 안팎 초안·수정 1회입니다. 시장조사·재무모델·발표자료는 별도입니다.

8. 자막 제작: 원가 32,000원 → 할인가 26,000원
대본 제공·한국어 영상 5분 이내·기본 SRT 제작입니다. 번역·영상 삽입은 별도입니다.

9. 데이터 크롤링: 원가 96,000원 → 할인가 77,000원
허용된 공개 정적 사이트 1곳·1,000행 이내·Excel·Python 결과물 기준입니다.

[진행 원칙]
고용 확정 및 숨고페이 결제 확인 후 작업을 시작합니다. 초안 작성 → 교차검수 → 최종 확인 → 요청 형식 파일 전달 순서로 진행합니다. 1차 수정은 기본 범위에 포함하며, 추가 범위는 동의 후 별도 거래로 진행합니다. 사문서 위조·허위 경력·표절·불법 목적 의뢰는 진행하지 않습니다.

샘플 구매가 가능한 상품은 할인가의 25%로 일부 결과물을 먼저 확인할 수 있으며, 본 작업 진행 시 샘플 결제액을 전액 차감합니다.

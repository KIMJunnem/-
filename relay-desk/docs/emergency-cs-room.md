# 고객응대 비상 방식 — 붙여넣기 (2026-09-24 감독, 준희 결정)

> Astra(Codex) 사용량 소진 동안 임시. 자동 확인·답장 규칙 방은 만들지 않는다(처음 안은 폐기).
- 준희가 숨고 채팅(요청서 + 대화)을 복사해 **감독방에 붙여 넣는다**.
- 감독방이 **바로 보낼 답장 한 통**을 쓴다: 자연스럽게, 가격·일정·꼭 필요한 정보만. 금액·납기·수정 횟수는 docs/astra-brief.md 값만. 없는 서비스·분량은 "확인 후 안내".
- 발송은 준희가 직접 복사해서 보낸다. 결제·환불·취소·분쟁은 답장 대신 준희 판단 메모.
- Astra가 돌아오면 준희가 보낸 방을 Astra에 알려 이어받게 한다(중복 답장 방지).

# 영상편집 문의 분류 — 아스트라에게 맡기는 지시 (붙여 넣기용)

> 2026-09-24 숨고 운영방. 준희 결정 "(다) 아스트라에 맡기기".
> 이유: 숨고 운영방(Claude)은 요청 내용 읽기가 자동 권한 검사에서 3번 막힘. 아스트라는 이미 숨고 탭을 쓰고 있음.
> 아래 "붙여 넣을 블록"을 준희가 아스트라 방에 그대로 넣는다. 결과 파일이 생기면 숨고 운영방이 묶음 요약을 채운다.

## 붙여 넣을 블록

```
[영상편집 문의 세기 — 읽기만, 한 번만]
숨고 "받은 요청" 목록 화면에서 분야가 '영상 편집'(또는 '개인 영상')인 요청만 보고 종류를 센다.
볼 수 있는 가장 오래된 것부터 오늘까지(최대 60일).

지킬 것
- 목록 화면에 보이는 글자만 본다. 아직 안 연 요청은 새로 열지 않는다(읽음 표시가 바뀜).
- 견적 보내기·채팅 답장·거절·숨기기·삭제·저장 버튼은 누르지 않는다. 이번 일로 고객에게 아무것도 보내지 않는다.
- 고객 이름·연락처·주소·지역·파일 링크는 적지 않는다.
- 목록만으로 모르는 칸은 "모름"으로 둔다. 추측으로 채우지 않는다.
- 로그인·사람 확인·비밀번호 화면이 나오면 멈추고 "준희 필요".

한 줄씩 적을 칸 (영상편집 요청 1건 = 1줄)
날짜 | 편집 종류(컷편집 / 자막 넣기 / 유튜브 편집 / 쇼츠 / 행사·웨딩 / 광고·홍보 / 모션그래픽 / 기타) | 용도 | 영상 길이 | 원본 개수 | 원하는 납기 | 고객이 적은 예산 | 추가 요구(썸네일·음악·색보정 등) | 요청 핵심 20자 이내 | 이미 견적 보냄?(예/아니오/모름)

끝에 셀 것
1. 목록에 보인 전체 요청 수와 그중 영상편집 수(분야별로 대략: 영상편집 / 자막 / 문서 / PPT / 이력서·자소서 / 기타)
2. 편집 종류별 건수
3. 예산 구간: 3만 미만 / 3~10만 / 10만 이상 / 안 적음
4. "말하는 영상(강의·인터뷰·브이로그 등) 컷편집 + 자막"에 들어가는 건수
5. 실제로 본 기간(가장 오래된 날짜 ~ 오늘)

결과는 relay-desk-site/docs/soomgo/video-edit-list-astra-20260924.md 에 새 파일로 저장한다(다른 파일은 고치지 않는다).
```

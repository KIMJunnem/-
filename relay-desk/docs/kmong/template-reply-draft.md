# 템플릿 상품 문의 답변 틀 — 초안 (2026-09-23, 크몽방)

대상: 2026-09-23 승인된 두 상품
- 소상공인 월손익 자동정리 엑셀 템플릿 (자료·템플릿 > 비즈니스 문서 > 기업 문서 양식)
- AI마케팅 입문자 템플릿 패키지 (자료·템플릿 > 마케팅 자료·키워드 > 마케팅·영업 자료)

상태: **초안**. 발송·등록하지 않았다. 상품 페이지 본문을 이 방에서 열지 못해(크몽 로그인 필요) 값은 [확인 필요]로 비워 뒀다.

## 원칙
- 상품 페이지에 실제로 적힌 내용 안에서만 답한다. 페이지에 없는 약속을 만들지 않는다.
- 템플릿은 파일을 바로 받는 상품이라 작업 범위·납기 이야기를 하지 않는다.
- 합니다체, 짧게, 질문은 하나. 외부 연락처·링크는 안내하지 않는다.
- 모르는 건 지어내지 않고 "확인 후 알려드리겠습니다"로 답한 뒤 준희가 확인한다.

## 공통 첫 줄
```
문의 주셔서 감사합니다. 보내주신 내용 확인했습니다.
```

## T-1. 내 상황에 맞는지 (업종·규모·용도)
```
문의 주셔서 감사합니다. 보내주신 내용 확인했습니다.
{고객이 말한 업종·상황}에 쓰실 수 있습니다. 이 템플릿은 {상품 페이지에 적힌 용도: [확인 필요]}를 정리하는 용도로 만들었습니다.
{한 가지 질문}
```
- 질문 순서: ① 지금 어떤 방식으로 정리하고 계신지 ② 꼭 넣어야 하는 항목이 있는지
- 페이지에 없는 업종까지 된다고 쓰지 않는다. 맞지 않으면 맞지 않는다고 답한다.

## T-2. 어떤 프로그램·버전에서 열리는지
```
문의 주셔서 감사합니다. 보내주신 내용 확인했습니다.
{상품 페이지에 적힌 파일 형식·권장 프로그램: [확인 필요]}에서 열립니다. {구글 시트·넘버스 등 호환 여부: [확인 필요]}
{한 가지 질문}
```
- 질문: 사용하시는 프로그램이 무엇인지
- [확인 필요] 값: 파일 확장자(xlsx 등), 최소 엑셀 버전, 구글 스프레드시트에서 수식이 그대로 도는지, 매크로 포함 여부

## T-3. 고쳐 써도 되는지 (수정·상업적 이용·재판매)
```
문의 주셔서 감사합니다. 보내주신 내용 확인했습니다.
내부에서 쓰시려고 항목을 고치시는 것은 {가능/불가: [확인 필요]}입니다. {상업적 이용 가능 여부: [확인 필요]} 파일을 그대로 다시 판매하거나 배포하시는 것은 안 됩니다.
{한 가지 질문}
```
- 질문: 어떤 항목을 바꾸고 싶으신지
- [확인 필요] 값은 상품 페이지의 '3가지 필수기재 사항'에서 그대로 가져온다: ① 저작권 귀속(전문가 귀속/고객 귀속) ② 상업적 이용 가능 여부 ③ 폰트 사용 정보.
  근거: 크몽 비승인 메일(2026-09-17)에서 이 세 가지를 서비스 설명에 기재하라고 요구했다. 승인된 두 상품에는 이미 적혀 있을 것이므로 그 문구를 그대로 인용한다.
- 재판매 금지 문장도 상품 페이지에 적힌 범위 안에서만 쓴다. 페이지에 없으면 [확인 필요]로 비워 둔다.

## T-4. 환불·교환
- 자료·템플릿은 다운로드 상품이라 환불 기준이 서비스형과 다르다. 기준은 [확인 필요]. 확인 전까지는 답하지 않고 준희에게 넘긴다.

## 준희가 채울 것
- 두 상품의 파일 형식·권장 프로그램·호환 범위
- 저작권 귀속 / 상업적 이용 / 폰트 정보 문구 원문
- 환불·교환 기준

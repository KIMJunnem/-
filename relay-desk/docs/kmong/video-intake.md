# 크몽 영상 파일 받는 방법 (2026-09-23, 크몽방)

## 첨부 한도 (감독 확인값)
- 한 번에 올릴 수 있는 파일: **6개**
- 파일당 최대 용량: **500MB**
- 출처: 크몽 가이드 "메시지 기능으로 전문가에게 문의하는 방법" (kmong.com/article/1833), 2026-09-23 감독 확인
- 허용 파일 형식(영상 확장자별 가능 여부): [확인 필요]
- 참고: 크몽 고객센터에도 같은 주제의 문서가 있다 — "전문가에게 문의·의뢰 시 첨부할 수 있는 파일의 용량 제한이 있나요?"(article 4406941308313), "[크몽 팁] 대용량 파일 공유하기"(article 4404205823001). 이 방에서는 본문을 열지 못했다(사이트 접근 차단).

## 500MB를 넘는 영상
- 크몽 안내: 대용량 파일은 **거래 성립 뒤** 이메일이나 파일 공유 프로그램으로 주고받는다 (감독 확인).
- **규칙 충돌 표시**: 답변틀 v3.1은 "외부 연락처·외부 링크를 우리가 먼저 안내하지 않는다"이다. 위 안내는 거래 성립 뒤에 한정되므로 문의 단계에서는 충돌하지 않는다. 다만 결제 후 안내 문구를 만들 때는 두 규칙이 겹치므로 감독·준희 확인이 필요하다.
  - 문의 단계(결제 전): 우리가 링크·이메일을 먼저 안내하지 않는다. 고객이 스스로 보낸 링크는 받는다.
  - 결제 후: 500MB 초과 영상은 크몽이 안내하는 방식으로 받는다. 이때 우리가 먼저 안내해도 되는지 [확인 필요].

## 문의 단계에서 쓸 문구 (초안, 승인 전)
- 영상이 500MB를 넘는다고 고객이 말한 경우:
```
영상 파일이 크면 결제 후에 나눠서 받거나 다른 방법으로 받을 수 있습니다. 먼저 영상 길이와 원어만 알려주시면 금액을 안내드리겠습니다.
```
  - 외부 링크·이메일을 먼저 말하지 않는 문장이다. 승인 전 초안.

# AI 채팅을 자연스럽게 만드는 설정 점검

기준일: 2026-09-18

사람처럼 느껴지는 상담은 말투 한 가지로 만들어지지 않는다. 현재 릴레이데스크는 모델 지시, 대화 상태, 응답 길이, 중복 방지, 전송 지연, 서비스 규칙을 함께 조정해야 한다. “사람 상담원인 척하기”가 아니라 자동 상담임을 고지한 상태에서, 고객이 다시 설명하지 않아도 되고 질문을 한 번에 하나만 받는 경험을 목표로 한다.

## 공식 OpenAI 문서에서 확인한 원칙

OpenAI 공식 문서는 모델에 응답 내용과 형식을 지시할 수 있지만 지시가 항상 보장되는 것은 아니므로, 프롬프트만 믿지 말고 애플리케이션에서 상태·길이·중복·전송을 검증해야 한다고 설명한다. 또한 대화형 앱에서는 이전 대화와 메시지 역할을 명확히 전달하고, 시스템·개발자 지시를 사용자 입력보다 높은 우선순위로 둔다.

## 설정 항목

| 항목 | 적용 기준 | 릴레이데스크 상태 |
| --- | --- | --- |
| 정체성 고지 | 자동 상담임을 첫 접점에 한 번만 알림. 사람 상담원이라고 주장하지 않음 | 적용됨 |
| 응답 길이 | 일반 답변은 2~4개의 짧은 문장, 가격·범위 안내는 필요한 항목만 구조화 | 적용됨 |
| 질문 수 | 한 번에 하나의 핵심 질문. 요청서에 있는 정보는 다시 묻지 않음 | 적용됨 |
| 맥락 유지 | 최근 대화·견적 사실·고용 상태·결제 상태를 함께 전달 | 적용됨 |
| 반복 방지 | 같은 메시지 ID·답변 지문·후속 이벤트를 저장하고 재전송하지 않음 | 적용됨 |
| 응답 지연 | 1.4~3.6초의 결정적 지연을 두고 입력 반영과 전송 결과를 확인 | 적용됨 |
| 문장 다양성 | 고객 질문에 먼저 답하고, 매번 같은 인사·가격·샘플 문장을 반복하지 않음 | 적용됨 |
| 가격 상담 | 고정 할인가를 기계적으로 반복하지 않고 범위를 줄인 대안이나 소폭 협의가를 제시 | 적용됨 |
| 다음 행동 | 진행·샘플·질문 중 하나를 고르게 하되 자연어 답변도 허용 | 적용됨 |
| 불확실성 | 결제·파일·전송 상태를 확인하지 못하면 완료형 표현과 재전송을 금지 | 적용됨 |
| 안전 경계 | 자동 상담임을 숨기지 않고 위조·허위 경험·개인정보 침해 요청을 차단 | 적용됨 |

## 자연스러움을 떨어뜨리는 패턴

- 고객이 이미 답한 분량·마감·자료를 다시 묻는 것
- 고객이 가격을 물었는데 접수 양식부터 요구하는 것
- 같은 메시지에 긴 소개, 가격표, 여러 질문을 한꺼번에 붙이는 것
- “확인했습니다”만 반복하고 실제 다음 행동을 안내하지 않는 것
- 견적 열람이나 짧은 긍정을 결제·고용 확정으로 해석하는 것
- 전송 결과가 불확실한데 보냈다고 말하거나 같은 파일을 반복 전송하는 것
- 자동 상담임을 숨기거나 실제 담당자 검토를 하지 않고 했다고 쓰는 것

## 현재 구현 위치

- `server/relay-server.js`의 `buildSoomgoAiReplyPrompt`: 대화형 말투, 한 질문 원칙, 가격 답변 우선, 고용·결제 상태 보호, 경쟁사 영업 인사이트를 모델 지시에 포함한다.
- `soomgo-chat-bot/chat-content.js`의 `sendChatText`: 1.4~3.6초 지연, 입력값 반영 확인, 전송 후 입력창 비움 확인을 수행한다.
- `soomgo-chat-bot/chat-content.js`의 중복·후속 상태 키: 메시지 지문, 답변 시간, 견적 후속, 무응답 후속을 저장한다.
- `server/relay-server.js`의 `SOOMGO_CHAT_DISCLOSURE`: 첫 접점에서 자동 상담 고지를 한 번만 사용한다.

## 다음 측정 기준

사람 같은 느낌은 주관적인 평가만으로 판단하지 않는다. 서비스별로 아래 지표를 기록한다.

1. 첫 답변 후 고객이 추가 설명 없이 답한 비율
2. 견적 후 고객 답변률
3. 고객 답변 후 동일 질문 재발생률
4. 답변 후 고용 전환률
5. 중복 발송·전송 불확실·수동 전환 건수
6. 고객이 자동 상담임을 묻는 비율과 불편 신고 건수

응답 속도를 더 늦추거나 이모지를 늘리는 것은 위 지표가 개선될 때만 조정한다. 말투 변화가 전환율이나 안전성을 악화시키면 이전 설정으로 되돌릴 수 있어야 한다.

# swan 견적용 샘플 첫 묶음

제작일: 2026-09-23. 실제 고객 작업물·후기·실적이 아닌 자체 제작 시연 자료다.

## 분담과 교차 검수
- Codex: 자체 원문 → 편집 문서 2쪽 → PPT 4장 제작, 렌더·파일 구조·글꼴 검사.
- Claude 감독방 Opus 5.5: 기존 자막 감사, 21초 영어/한국어 비교 영상, 번역 수정, 문서·PPT 원문 보존·가독성 교차 검수.
- Codex: Opus 영상 디코딩·SRT 검사·번역 대조, 로컬 독립 전사 추가 검증.
- 유료 모델 API 호출 0회. 기존 구독 및 로컬 도구 사용. 고객 발송·상품 게시 없음.

## 사용할 파일
- Swan_Document_Before_After.pdf: 자체 메모 1쪽과 편집본 2쪽을 순서대로 비교.
- Swan_Document_Before_After.jpg: 견적 첨부용 비교 미리보기.
- Swan_01_Before.docx / .pdf: 자체 작성 원문.
- Swan_02_Edited_Report.docx / .pdf: 편집본. PDF는 글꼴·레이아웃 고정 미리보기용.
- Swan_03_Report_to_PPT.pptx: 편집 가능한 4장, Pretendard Regular/Bold 포함.
- Swan_PPT_Preview.jpg: 4장 전체 미리보기.
- Swan_Subtitle_Compare_21s.mp4: 영어 대사와 한국어 번역 자막을 위아래로 비교하는 21초 영상.
- Swan_Subtitle_Compare_21s_ko.srt / _en.srt: 비교 영상용 자막 5개.
- verification.json: 실제 검사 결과 및 미확인 항목.

## 확인과 한계
문서 3쪽(원문 포함), PPT 4장의 렌더링을 확인했다. 문서의 글꼴 대체와 단어 중간 줄바꿈을 수정했다. PPT 패키지·레이아웃 검사와 재가져오기 검사 통과. Opus가 제안한 번역 자막 설명, 전문용어 풀이, 표현 완화, 글꼴 포함을 반영했다.

영상·음성 21초, 전체 디코딩 오류 없음. SRT 5블록의 순서·겹침·최대 2줄·줄 길이·읽기 속도 검사 통과. 고객 스크립트를 주지 않은 로컬 Whisper medium 전사에서 대사 5개를 확인했다. 단어 시각은 근사치이며 정확한 음성 경계의 정답은 아니다. Windows Word·PowerPoint 직접 실행, 스마트폰 재생·플랫폼 재압축 후 검사는 수행하지 않았다.

## 견적에 붙일 때
문서 문의에는 문서 비교 1개, PPT 문의에는 PPT 미리보기 1개, 자막 문의에는 자막 비교 영상 1개를 고른다. 관련 없는 샘플을 묶어 보내지 않는다. 소개 문구 예시: “작업 형태를 보실 수 있도록 자체 제작한 샘플을 함께 보내드립니다.” 실제 고객 원자료로 만든 것처럼 말하지 않는다.

이전 build/shorts-clean.mp4는 이미 자막이 포함된 구판이며 싱크 문제가 보고됐다. 원본 또는 추천 샘플로 사용하지 않는다. 본 폴더의 21초 비교 영상과 혼동하지 않는다.

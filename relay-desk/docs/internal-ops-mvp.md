# Relay Desk 내부 운영 모듈 MVP

아스트라가 제안한 내부 도구를 기존 숨고 수집·상담·큐·스케줄러·납품 게이트와 분리된 읽기 전용/시뮬레이션 계층으로 시작한다.

## 범위

- 장애 시뮬레이터: `POST /api/internal-ops/simulate`는 네 가지 장애 시나리오만 실행하며 외부 호출은 0건이다.
- 예외 복구 워크벤치: `GET /api/internal-ops/exceptions`는 제공된 상태 스냅샷의 보류·결과불명 항목만 보여준다.
- 손익·정산 대사: `POST /api/internal-ops/profit`는 입력된 원장 스냅샷을 계산한다. 입금 미확인액은 확정 수익으로 표시하지 않는다.
- 용량·납기: `POST /api/internal-ops/capacity`는 수락/납기검토/수용불가를 계산한다.
- 범위 비교: `POST /api/internal-ops/scope-diff`는 동의가 필요한 변경만 표시한다.
- 전환 분석: `POST /api/internal-ops/funnel`은 이벤트 단계별 건수를 집계한다.
- 운영 지식: 모듈 함수로 초안 레코드를 만들며 승인 상태를 자동으로 바꾸지 않는다.

## 권한 경계

이 MVP는 숨고 채팅, 결제, 파일 전달, 거래확정, 브라우저 매크로, Astra를 호출하지 않는다. 따라서 계산·시뮬레이션 결과는 외부 완료 증거가 아니며, 고객 채널 상태를 바꾸지 않는다. 외부 실행 연결은 별도 승인과 실제 증거 검증 후에만 추가한다.

## 검증

`node tests/internal-ops.cjs`로 핵심 불변조건을 확인한다. 롤백은 새 파일 삭제와 서버 라우트 제거로 가능하며, 기존 거래 데이터는 변경하지 않는다.

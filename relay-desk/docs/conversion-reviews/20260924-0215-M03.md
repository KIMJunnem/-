# M03 — 문서 디자인 요청과 글 작성 견적의 불일치

관측: 2026-09-24 02:15~02:18 KST. Codex 숨고 메인 채널.

## 확인한 사실

- 실제 숨고 대화 2건의 요청 상세와 발송된 견적을 직접 열어 대조했다. 고객 식별정보와 대화 전문은 이 공유 보고에 넣지 않는다.
- 사례 A: 요청은 인포그래픽 디자인, 결과 형식 PDF, 1쪽. 실제 견적은 글 정리·작성 21,000원이며 수정 2회. 9/23 21:57 발송분이 02:16 관측 시 안읽음이다.
- 사례 B: 기존 보고서를 보기 좋게 디자인, 한글, 16쪽. 실제 견적은 새 글 작성 경로의 147,000원·2~3일. 9/23 16:58 발송분이 02:17 관측 시 안읽음이다.
- 두 대화 모두 견적 뒤 실제 고객 질문은 없다. 따라서 무응답을 문구/가격 탓으로 단정할 수 없다. 견적 노출·읽음이 앞단의 미확인 구간이다.
- 위 두 건은 문제를 확인하려고 골라 본 표본이다. 전체 오류율·전환율의 분모로 사용하지 않는다.

## 원인 확인 — 코드 수정 없이 실행

`M03-pricing-probe.cjs`에서 현재 `server/pricing-table.js`의 함수를 실제 호출했다. 실제 고객 원문 전체나 서버 저장 데이터를 호출한 것이 아니라, 동일한 의미의 합성 입력으로 좁혀 재현했다. 외부 요청 0회.

| 합성 입력 | 현재 결과 | 해석 |
|---|---|---|
| 인포그래픽 디자인 / 기관 연구과제 / 1쪽 | writing, 21,000원, 수정 2회 | 디자인 범위 확인 없이 writing. 연구과제도 학교 과제로 처리 |
| 기존 보고서를 좀더 보기 좋게 디자인 / 16쪽 | writing, 147,000원, 2~3일 | 디자인만·레이아웃·편집 등 정해진 표현이 없으면 writing |
| 내용 유지 + 레이아웃 편집 / 16쪽 | formatting, 32,000원, 당일~1일 | 비교용 합성 입력. 고객에게 새 견적으로 안내하지 않았음 |
| 제공 자료로 소개글 작성 / 1쪽 | writing, 21,000원 | 일반 글 작성 대조군 |

근거: `server/pricing-table.js:38` documentWorkType, `:43` 제한적인 서식 정리 정규식, `:44` writing 폴백. `:82` isSchoolAssignment, `:84`의 포괄적인 과제 정규식. `:115` documentQuote에서 해당 결과로 가격·문구·수정 횟수 선택. 실행 결과는 M03-pricing-probe-results.json.

인포그래픽을 무조건 formatting으로 바꾸는 것은 해법이 아니다. 데이터 시각화·일러스트 제작은 단순 문서 서식 정리와 다른 범위다. B도 고객 파일과 내용 유지 여부를 확인하기 전 금액을 32,000원으로 바꿀 근거는 없다.

## 후보 3개와 이번 조치 1개

1. 선택: Codex 상담에서 요청 원문과 기존 견적의 작업 종류를 대조하고, 불일치하면 범위 확인 후 다음 안내를 하는 절차를 적용.
2. 보류: 자동 견적의 문서 작업 종류 판정 수정. 견적봇·공유 서버 변경은 이번 예약 범위 밖이므로 감독에게 재현 근거만 전달. 코드/설정/재시작 없음.
3. 보류: 무응답 고객 일괄 후속 메시지 또는 할인. 두 사례가 미열람이고 새 질문이 없어 반복 연락하지 않음.

단일 변경 변수는 **기존 견적을 그대로 재사용하기 전에 작업 종류를 확인하는 상담 단계**다. 가격·상품·자동 견적 문구는 바꾸지 않았다. customer-channel-integration.md에 반영했다.

### 적용 규칙

- 기존 글의 서식·디자인 정리 요청이면 내용 유지 여부부터 확인한다. 새 글 작성 가격·범위를 그대로 반복하지 않는다.
- 인포그래픽 요청은 단순 문서 편집으로 확약하지 않는다. 참고 이미지와 원자료를 확인해 제작 범위·가능 여부를 먼저 검토한다. 문서 샘플을 인포그래픽 제작 실적으로 소개하지 않는다.
- 연구과제·기업 보고서라는 이유만으로 학교 과제라고 설명하지 않는다. 기존 합의된 수정 횟수를 임의 변경하지 않는다.
- 고객의 실제 질문에 먼저 답한 뒤, 다음 진행에 필요한 질문 하나만 덧붙인다. 새 질문이 없거나 다른 고수를 고용한 대화에는 이 점검을 이유로 새 메시지를 보내지 않는다.

적용 대상: 앞으로 실제 답장이 온 문서/디자인 상담. 자동 발송에는 적용되지 않음. 확인 표본 목표는 다음 적격 상담 5건, 24시간 뒤 표본 수 점검. 5건 미만이면 효과 판정 보류. 주 지표는 범위 불일치가 해소됐는지, 보조 지표는 고객 재답장/범위 합의/결제다. 가격 효과나 매출 개선을 현 단계에서 주장하지 않는다.

중단 조건: 확인 질문이 고객 질문에 대한 답을 지연시키거나 기존 합의를 뒤집는 경우. 백업의 기존 상담 지침으로 복구하되 잘못된 범위를 확약하는 행동은 하지 않는다. 백업: backups/conversion-review-20260924-0215/.

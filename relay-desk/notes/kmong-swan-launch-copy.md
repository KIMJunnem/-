# 크몽 swan 운영 문구

## 프로필 제목

빠른 자막 제작·깔끔한 문서 글 작성

## 프로필 소개

안녕하세요, swan입니다. 자막과 일반 문서를 빠르고 깔끔하게 만드는 일을 합니다. 30분이 넘는 프랑스어 영상도 발화 타이밍에 맞춰 자막을 제작한 경험이 있어요. 문서는 보내주신 자료를 바탕으로 보고서, 안내문, 소개문, 요약문처럼 용도에 맞게 정리합니다. 상담은 크몽 메시지로 진행하며, 분량과 자료, 파일 형식, 마감일을 본 뒤 금액과 일정을 정합니다. 완성본은 한 번 더 직접 확인해서 보내드립니다.

## 자동 응답

안녕하세요, swan입니다. 자막은 영상 길이와 언어, 대본 유무, 필요한 파일 형식과 마감일을 남겨주세요. 문서는 용도와 분량, 가지고 계신 자료, 파일 형식과 마감일을 알려주시면 됩니다. 내용을 본 뒤 가능한 일정과 최종 금액을 말씀드릴게요.

## 문서·글 작성 서비스

### 제목

제공 자료를 바탕으로 깔끔한 문서와 글을 작성해 드립니다

### 설명

고객이 제공한 자료와 메모를 바탕으로 보고서·안내문·소개문·요약문·일반 원고를 읽기 쉽게 정리합니다. 기본형은 1,500자 이내, 제공 자료 중심 작성, 기본 수정 1회를 포함하며 21,000원입니다.

1,000자 또는 A4 1쪽 초과는 10,000원부터, 기본 범위를 넘는 자료조사는 15,000원부터, 추가 수정은 회당 10,000원입니다. 작업 순서를 앞당기는 긴급 작업은 기본가의 30%가 추가됩니다. 추가 작업은 범위와 금액을 먼저 안내하고 동의 후 진행합니다.

진행 전 문서 용도, 분량, 제공 자료, 원하는 파일 형식, 마감일을 확인합니다. 논문·학위논문·시험 답안·허위 자료·표절 문서는 진행하지 않습니다. 확인되지 않은 사실이나 출처는 임의로 만들지 않습니다.

작업 시작 전 취소는 크몽 규정에 따라 처리합니다. 작업 시작 후에는 진행된 분량을 제외한 범위에서 협의하며, 납품 후 단순 변심에 따른 환불은 어렵습니다. 합의한 범위 안의 오탈자와 자료 반영 오류는 확인 후 수정합니다.

## 자막 제작 서비스

영상의 발화 타이밍을 확인해 SRT 또는 VTT 자막 파일을 제작합니다. 기본형은 영상 5분 이내, SRT 파일, 기본 수정 1회를 포함하며 32,000원입니다. 영상 길이·언어·대본 유무·납품 형식·희망일을 확인한 뒤 최종 금액과 일정을 안내합니다.

# 파이버 "You're not visible yet" — 확인 메모 (2026-09-23, 지시 6)

> **이 방은 파이버 화면을 열지 않았다.** 이 방의 절대 규칙(준희가 방을 만들 때 준 것): "파이버·업워크 페이지를 봇이 읽거나 누르지 않는다. 확장프로그램·자동 로그인·자동 전송·페이지 수집 전부 금지." 지시 6의 1번(크롬에서 대시보드 읽기)은 이 규칙과 부딪혀 **실행하지 않았다.** 준희가 이 규칙을 풀어 주기 전까지는 아래 확인을 준희가 직접 한다.

## 확인한 사실

- 문구 "You're not visible yet": Codex 숨고 메인 채널이 19:49에 판매 대시보드에서 봤다고 기록(docs/astra-supervisor-handoff-20260923.md). 이 방은 직접 보지 않음
- 파이버 공식 도움말에서 이 문구 설명은 찾지 못함(검색 결과는 커뮤니티 글·블로그뿐). 공식 문서는 파이버 페이지를 열어야 해서 읽지 않음

## 준희가 화면에서 볼 것 (읽기만, 5분)

1. **판매 대시보드** — "You're not visible yet" 옆·아래에 붙은 설명 문장과 버튼 이름을 그대로 적기(누르지 말고)
2. **Gigs 목록** — 자막 상품의 상태 탭: Active / Pending approval / Requires modification / Draft / Paused 중 어디에 있는지
3. **프로필 완성도** — 사진·소개·언어·기술 칸 중 비어 있는 것, "Complete your profile" 같은 안내가 있는지
4. **본인 인증(ID verification)** 안내가 떠 있는지
5. **Availability(휴가·비활성) 표시**가 켜져 있는지
6. **알림(종 모양)·이메일**에 파이버에서 온 "gig approved / requires modification / verify" 메일이 있는지

적은 문구를 이 방에 붙여 주면, 무엇을 해야 하는지 단계별로 정리한다.

## 흔한 원인 — 전부 [추정] (공식 확인 아님)

**① 제목 (A안)**
```
I will create accurate Korean SRT subtitles for your video with full sync check
```

**② 설명 (Description)**
```
Need Korean subtitles that stay in sync all the way through?

A common problem with auto-generated subtitles: they look fine at the start, then slowly drift and end up seconds off by the middle of the video. I check timing across the whole video, from start to finish (not a quick spot check), and fix drift where it starts.

What I offer
- Foreign-language video -> Korean subtitles (SRT): English or French audio. Other languages: please ask before ordering.
- Korean video -> Korean subtitles (SRT)
- Optional: subtitles burned into your video (MP4)

How I work
I use AI tools for the first transcript and draft translation. Then I review the result as a native Korean speaker, rewrite lines that sound unnatural to Korean viewers, and check timing against the audio. Before delivery, the timing is checked against the source from start to finish.

Included
- SRT file ready for YouTube, Premiere, DaVinci, etc.
- 2 revisions

Before you order, please message me with your video length and language. If your language or audio quality is something I can't handle well, I'll tell you honestly before you pay.
```

**⑤ FAQ 5개**

Q1. Do you use AI?
```
Yes. I use AI tools for the first transcript and the draft translation. Every file is then reviewed by me, a native Korean speaker, and checked for timing before delivery. I don't claim it's 100% handwritten.
```
Q2. What does "full sync check" mean?
```
Auto subtitles often drift a few seconds by the middle of a video. I check the timing from start to finish, not just a few samples, and fix the point where the drift begins.
```
Q3. Which languages can you translate from?
```
English and French. For any other language, please message me before ordering. I'll check whether I can deliver good quality for that language, and if I can't, I'll say so before you pay.
```
Q4. What if I'm not happy with some lines?
```
Every package includes 2 revisions. Tell me the timecode or the line, and I'll fix it.
```
Q5. My video is longer than 30 minutes.
```
Send me a message with the length, and I'll send you a custom offer.
```

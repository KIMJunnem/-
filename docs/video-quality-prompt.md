# 영상 제작방 품질 기준 프롬프트 (2026-09-24 감독, 준희 요청 "돈 받을 만한 퀄리티")

```
[영상 제작 품질 기준 · Swan · 이 방의 모든 영상 작업에 적용]
기준: 고객이 돈 내고 받아도 아깝지 않은 결과. "대충 붙인 슬라이드쇼"로 보이면 실패다. 아래 순서를 건너뛰지 않는다.

0. 【가장 먼저 · 최우선】 AI 티 점검 (준희 9/24: "영상은 못하는 사람이 했나… AI인가 두 가지인데, 글은 문맥 하나만 삑나도 AI가 썼나 싶다")
- 컷 반 박자 늦음·자막 위치 조금 어색함 정도는 "사람 실수"로 넘어간다. 아래 3가지는 바로 "AI가 했다"로 읽히므로 하나라도 걸리면 무조건 실패(채점과 무관, 준희에게 보내지 않음)
- ① 자막·화면 글자: 오탈자 0, 문맥 튀는 문장 0, 어색하게 매끄러운 번역투 0. 자막 전체를 글로 뽑아 한 번 따로 읽고, 고객 말과 뜻이 다른 곳이 없는지 대조(싱크 검수와 같이). 고유명사(이름·가게명·지명)는 고객 자료 표기 그대로
- ② AI 목소리 금지: TTS 내레이션·더빙을 넣지 않는다. 소리는 원본 음성과 허가된 음악만
- ③ AI 생성 이미지·영상 금지: 고객이 준 사진·영상과 출처 분명한 자료만. 빈 곳을 생성 이미지로 채우지 않는다(손가락·글씨 뭉개짐 = 즉시 들킴). 고객이 AI 영상을 직접 준 경우만 예외(고객 자료)
- 결과 보고 맨 위에 "AI 티 점검: ①글자 ②목소리 ③이미지 — 통과/실패" 한 줄

1. 먼저 계획(렌더 전에 이 방에 표로 남긴다)
- 스토리보드를 장면 단위로 쪼갠 표: 번호 · 들어갈 사진/영상 · 문구(그대로) · 길이(초) · 전환 · 음악 구간
- 전체 길이 합계가 스토리보드/요청 길이와 맞는지
- 모자란 자료(사진 수·문구·음악 선택)가 있으면 임의로 채우지 말고 목록으로 준희에게 묻는다
- 스토리보드에 우리가 못 하는 연출(캐릭터 애니메이션·3D·복잡한 모션그래픽)이 있으면 렌더 전에 "대신 이렇게 하겠다" 대안을 적고 준희 확인

2. 화면 규칙
- 규격: 요청대로 가로 1920x1080 또는 세로 1080x1920, 30fps, H.264(CRF 18, yuv420p), AAC 192k
- 사진 비율이 안 맞으면 검은 띠 금지 → 같은 사진을 흐리게 깐 배경 위에 원본을 올린다
- 사진은 멈춰 있지 않게 천천히 확대/이동(3~5초 동안 100%→106~108%), 방향은 장면마다 번갈아
- 사진 1장당 3~5초(스토리보드 우선). 영상 클립은 흔들린 앞뒤를 잘라 낸다
- 전환은 한 가지 계열로 통일(부드러운 페이드 0.5~0.8초). 장면마다 다른 효과 남발 금지
- 밝기·색이 튀는 사진은 맞춘다(너무 어두우면 밝기 보정)

3. 글자 규칙
- 글꼴: Pretendard 또는 Noto Sans KR(굵게는 제목만). 기본 글꼴·굴림 금지
- 흰 글자 + 옅은 그림자(또는 얇은 테두리), 화면 가장자리 5% 안쪽(안전 영역)
- 제목 화면 높이의 6~8%, 본문 4~5%, 한 줄 16자 이내·최대 2줄
- 나타날 때·사라질 때 0.3초 페이드. 문구는 스토리보드 그대로, 맞춤법 확인
- 오프닝 제목 화면·마지막 마무리 화면은 스토리보드에 없어도 제안(2~3초)

4. 소리 규칙
- 음악 시작 1초 페이드인, 끝 2~3초 페이드아웃, 영상 끝과 음악 끝을 맞춘다(중간에 뚝 끊기 금지)
- 전체 소리 크기 -14 LUFS 기준으로 맞추고, 최고점 -1dB 넘지 않게
- 말소리가 있는 구간은 음악을 12dB 정도 낮춘다
- 음악은 준희가 준 것 또는 사용 허가가 분명한 것만. 출처를 기록한다

5. 자체 검수(통과 못 하면 준희에게 보내지 않는다)
- 장면이 바뀌는 지점마다 화면 캡처 → 한 장짜리 모아 보기 이미지로 확인: 검은 화면·잘린 얼굴·글자 가장자리 넘침 없음
- 검은 프레임 검사, 소리 최고점 검사, 전체 길이 확인
- 스토리보드 대조표: 장면마다 "요청 → 실제" 한 줄씩, 빠진 장면 0
- 0번 AI 티 점검 통과 확인(실패면 채점하지 않고 고친다)
- 스스로 5점 척도 채점: 흐름 · 화면 완성도 · 글자 · 소리 · 스토리보드 일치. 하나라도 4점 미만이면 고치고 다시
- 결과 보고: 미리보기 파일, 모아 보기 이미지, 대조표, 채점, 고친 점. 최종 납품은 준희 승인 뒤

6. 금지
- 자료가 없는데 비슷한 걸 지어내기, 워터마크 있는 자료, 출처 모르는 음악
- 고객 영상·사진을 PC 밖(클라우드)으로 옮기기(decisions 7-6·7-7)
```

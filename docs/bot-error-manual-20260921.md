# 숨고 봇 오류·예외 상황 매뉴얼 (2026-09-21)

대상: 요청 견적봇(`soomgo-bot-extension/content-v3.js`, 0.4.12), 고객 채팅봇(`soomgo-chat-bot/chat-content.js`, 0.3.18), 서버 응답 규칙(`server/relay-server.js`, `server/reply-guards.js`, `server/link-inspector.js`, `server/attachment-reader.js`, `server/office-text.js`).
확인 방법: 코드 읽기 + 고객 메시지 35개를 서버 규칙에 직접 넣은 결과 + 모의 숨고 화면 브라우저 시험.

## C. 운영(사람이 할 일)

1. 숨고 탭은 두 개: '받은 요청' 탭 하나(요청봇), '채팅' 탭 하나(채팅봇). 두 봇은 서로의 화면으로 넘어가지 않는다. 같은 종류 탭을 더 열면 나머지는 대기한다.
2. 두 탭은 각각 별도 창으로 띄워 두기.
3. 숨고 캐시(견적 보낼 때 차감되는 충전금)가 부족해 봇이 멈추면 충전한 뒤 패널에서 ON.
4. 담당자 확인 건(흥정·재촉·첨부·링크 문서)은 알림방(Claude 예약 작업, 1시간마다)이 폰으로 알려준다. 서버 목록: `GET /api/attention`.
5. 서버 재시작과 봇 배포는 Relay Desk `/api/admin/restart`로 Claude가 처리.

## D. 남은 과제

- 첨부 판독: 숨고 파일 서버가 봇의 내려받기를 막으면(CORS) 판독 없이 알림만 간다. 실제 파일 1건으로 확인 필요. 배포용·암호 한글, 스캔만 된 한글·워드는 글자를 못 뽑는다. 옛 .doc·.ppt·.xls는 미지원. 드라이브 큰 파일(바이러스 검사 안내가 뜨는 크기)은 자동으로 받지 않는다.
- 숨고 화면 개편 시 입력창·버튼 문구 변경 대응(현재는 2회 실패 후 건너뛰고 상태 표시).
- 크몽 봇은 이번 점검 범위 밖.

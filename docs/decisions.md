# Relay Desk(Swan) 확정 결정

> 상태: **초안 (2026-09-23 감독 작성, 준희 확인 전)**
> 출처: 스완 프로젝트 지침 + 준희가 대화에서 직접 정한 결정 기록. 날짜가 늦은 결정이 앞선 결정을 대신한다.

## 1. 서비스 범위

| 서비스 | 상태 |
|---|---|
| 자막(subtitle) | 주력. 강점은 싱크 검수 |
| 일반 문서(document_writing) | 판매 중. 학교 과제 레포트 받음. 논문·학위·학술 원고는 받지 않음 |
| PPT(presentation) | 판매 중. 9/22에 보류 해제(T1 보고형 템플릿). 연설·강연도 T1로 처리. 제작 방식 (9/23 확정): **Codex 대화방(구독) 자동 제작** — 서버가 astra-room-bridge에 production_draft 사건을 올리고 Codex 대화방이 슬라이드 JSON을 만들어 돌려줌 → 로컬 렌더. API 제작 안 함. GPT 구독 10/19 종료 후 대안은 그때 정함. 구독 판매용 사용은 준희가 괜찮다고 함(9/23). PPT 파일 생성용 pptxgenjs 설치 승인(9/23, 저장소 로컬 설치만). Codex 대화방 이름은 "아스트라"로 바꿈(준희, 9/23). 아스트라에 보내는 제작 건에는 항상 "플러그인을 적극 활용하라"는 지시를 넣음. 아스트라가 제작 건(production_draft)을 가져가는 Codex 자동화 만들기 승인, 아스트라 방에 E절(PRODUCTION_DRAFT) 붙여 넣음(준희, 9/23). 글꼴 포함·검사용 python-pptx·fontTools 설치 승인(9/23) |
| 번역 자막 (외국어 영상 → 한국어 자막) | **판매함**. subtitle 서비스 안에서 처리. 가격은 자막 금액 + 번역 가산 20% |
| 문서 번역(translation_en) | **판매 안 함**. 가격 미정. "영어 번역 판매 안 함"은 이 문서 번역만 가리킴 |
| 대본·시나리오 | 판매함 (9/23). 자동 견적 없이 견적 판단 알림 → 준희가 가격 결정 |
| 자소서·이력서 대필 | 하지 않음 |
| 속기사무소 도장이 필요한 속기·녹취록 | 받지 않음 |

- 자막 납품: 한국어 자막만(한국어 영상, 또는 외국어 영상을 한국어로 번역한 자막). 외국어 자막 납품은 범위 밖
- 번역 자막 판매 근거(9/23 준희): 크몽 답변틀 D항목("번역 자막은 A·B로 받는다"), 자막 번역 가산 20% 승인, 실거래 1건이 프랑스어 → 한국어 자막
- 자막 기본 납품은 SRT만. MP4는 자막 삽입 옵션일 때만. 번역용 원어 SRT는 내부 작업 파일이라 납품하지 않음

## 2. 가격 (숨고·크몽 같음, 값은 services/*.json에만)

- 자막: 5분 32,000원 / 10분 49,000원 / 30분 89,000원 / **30분 넘으면 5분마다 10,000원** (9/23 20시 준희 "더 싼 쪽", 이전 20,000) → 33분 99,000 · 45분 119,000 · 60분 149,000
- 번역 자막 가산: 자막 금액의 20%(천 원 단위 반올림) → 5분 38,000 / 10분 59,000 / 33분 119,000원(99,000×1.2)
- 자막 삽입: 5분당 15,000원 (번역 가산 뒤에 더함)
- 문서(글 작성): **A4 2쪽까지 21,000원, 추가 1쪽마다 9,000원** (9/23 20시 준희 "더 싼 쪽" — 숨고 계산값 유지, 크몽·추가금 10,000원 표기는 9,000원으로 맞춤) → 3쪽 30,000 · 6쪽 57,000
- PPT 자료조사: 견적 금액에 자동으로 더하지 않음(9/23 준희 "더 싼 쪽"). 조사가 필요하면 질문 줄에서 10,000원 추가를 안내하는 지금 방식 유지
- PPT 추가 수정: 1회 10,000원
- 파이버(USD, 9/23 17시 변경 — 파이버는 5달러 단위만 받음): 5분 **$25** / 10분 **$45** / 30분 **$75**. 자막 삽입·추가 분·추가 수정 옵션은 파이버에 등록 안 함(카테고리 목록에 자막 입히기 없음, 달러 가격 미정) → 요청 오면 준희가 맞춤 견적. 30분 초과도 맞춤 견적
- 긴급 할증 없음. 출시 할인 30%는 범용 계산 경로에만
- 가격 조정은 구조 개편이 끝나고 실제 문의 데이터가 쌓인 뒤에 함. 준희가 금액을 직접 적어 승인할 때만 바꿈
- 실거래 기준점: 33분 영상 자막 94,000원(과거 거래 기록. 지금 계산 99,000원)

## 3. 수정 횟수·납기

- 수정: 자막 2회 / 문서 3회 / PPT 2회 / 학교 과제는 서비스 상관없이 2회, 이후 추가금
- 자막 납기: 영상 길이와 상관없이 당일~1일
- 문서 납기(숨고·크몽 통일, 9/23 20시 준희): 5쪽 이하 당일~1일 / 6~15쪽 1~2일 / 16쪽 이상 2~3일 (숨고 계산 규칙). 크몽 "자료 받은 날 +1일"은 폐지
- 크몽 자막 납기: 숨고와 같게 길이와 상관없이 당일~1일. 답변틀 v3.1의 "30분 이상 +2일"은 자막에서 폐지 (9/23)
- 파이버 납기: Basic 2일 / Standard 2일 / Premium 3일

## 4. 납품·검수

- finalGrade.mode = manual. 모든 납품은 준희 승인 뒤에만 나감
- 숨고페이 결제 확인 전에는 최종 파일을 전달하지 않음
- 자막 싱크 검사: 샘플이 아니라 전 블록 대조. 독립 전사가 없으면 manual_review
- checkParams provisional=true 유지. false 전환은 준희가 실제 영상을 확인한 뒤 결정
- 번역 자막 두 단계 싱크 검사를 만든다 (9/23): ① 시각 맞춤(무료) ② Jev 내용 대조(유료, 33분 1건 약 27원 [추정])
  - 참고용: 납품을 막지 않고 밀린 구간만 표시. 자동 보정 없음, 수정안만 만들고 사람이 확인 후 적용
  - 자동 유료 차단(automaticPaidQuotesPaused=true) 동안은 관리자 경로·버튼으로만 실행
  - 고객 이름은 가리고 파일명은 보내지 않음. 기존 Jev 하루 예산 안에서

## 6. 봇·발송

## 7. 고객 문구

- 주 타겟은 40~50대. 이 층은 가격보다 "대충 해주고 돈만 받을까"를 걱정함
- 첫 줄: 숨고 견적은 **"안녕하세요. 문의 주신 ‘(요청 주제)’ 건으로 연락드립니다."**(주제를 못 읽으면 "안녕하세요. ○○ 작업으로 문의 주셔서 감사합니다.") — 9/23 18시대 준희가 16:16 새 문구 채택 / 크몽 "문의 주셔서 감사합니다. 보내주신 내용 확인했습니다." (9/23)
- 합니다체. 금액은 하나만, 납기는 날짜로, 확인 질문은 하나만. 할인 이유는 말하지 않음. 전문용어는 풀어 씀
- 숨고페이 결제와 수정 포함을 강조. 숨고 견적의 결제 줄은 "결제는 숨고페이로 진행하고, 결과물을 확인하신 뒤 거래를 확정하시면 됩니다."("안전결제"라는 말은 빠짐 — 준희가 알고 고름, 9/23)
- 사람이 다 했다고 거짓으로 쓰지 않음. 물으면 AI 사용 사실대로
- 크몽 답변틀 v4: 자막 싱크 설명 문장과 "영상 20분 이상 결제 전 앞부분 1~2분 무료 샘플"은 유지 (9/23 준희)

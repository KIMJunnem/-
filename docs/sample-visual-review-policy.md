# 제작물 최종 시각 검수 — 사용자 지시, 2026-09-23

사용자: “눈은 너밖에 없으니까 꼭꼭 너가 검수해.”

최종 시각 검수 담당은 이 Codex 작업이다. Opus 등 다른 모델의 보고나 프로그램 검사 통과만으로 고객용 승인 상태를 부여하지 않는다.

- 문서·PPT: 실제 렌더링의 모든 페이지·슬라이드를 직접 확인한다. 글꼴 대체, 단어·문장 잘림, 겹침, 여백, 강조, 읽기 순서, 한글 가독성과 브랜드 톤을 본다.
- 영상: 자막 전체 항목의 표시 장면, 첫·끝, 주요 전환, 어두운 장면을 직접 확인한다. 화면 가림, 대비, 줄바꿈, 워터마크와 출처 가독성을 본다.
- 싱크: 정지 화면과 파일 검사만으로 음성 동기화가 정확하다고 판정하지 않는다. 음성 시각 검증과 전사 대조 결과 및 한계를 별도로 남긴다.
- 수정 후에는 수정된 출력 파일을 다시 렌더링하고 영향받은 페이지·장면을 재검수한다.
- 기록에는 최종 파일 경로와 버전, 확인한 페이지·시각, 남은 문제, 미실시 검증을 적는다. 보지 못한 부분은 확인했다고 쓰지 않는다.
- 발견한 결함은 수정하거나 사용 보류한다. 확인되지 않은 결과물을 검수 완료로 고객에게 넘기지 않는다.

이 문서는 제작·검수 운영 기준이다. 서버의 자동 발송 차단 기능을 구현하거나 변경한 것은 아니다.

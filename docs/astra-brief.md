## 쓰는 법 (내부 규칙)

- 금액·납기·수정 횟수는 Relay Desk가 고객에게 보낸 견적 값만 쓴다. 이 표에 없는 새 숫자를 만들지 않는다(decisions.md 6절).
- 이 표와 실제 보낸 견적이 다르면 보낸 견적을 따르고, 차이를 준희 확인으로 올린다.
- 결제·환불·취소·분쟁은 답하지 않고 준희 확인으로 넘긴다(decisions.md 6절).
- 모든 납품은 준희 승인 뒤에만 나간다(finalGrade.mode = manual). 결제 확인 전에는 최종 파일을 보내지 않는다.
- 금액은 하나만, 납기는 날짜로, 확인 질문은 하나만. 가격을 내린 이유나 정상가는 말하지 않는다(decisions.md 7절).

- 포함 범위(services/subtitle.json scope 그대로): 한국어 영상 N분 이내의 자막 파일(SRT) 제작과 수정 2회입니다.

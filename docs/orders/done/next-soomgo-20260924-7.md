## 왜
준희 말로는 숨고 문의 중 영상편집이 가장 많다. 지금 우리는 영상편집을 팔지 않는다(자막 안내문에 "영상 편집 미포함"). 받을 종류(예: 말하는 영상 컷편집+자막)를 정하려면 실제 요청이 어떤 모양인지 숫자가 필요하다. 그리고 Relay가 영상편집 요청을 자막 등으로 잘못 보고 견적을 만든 적이 있는지도 본다(잘못된 견적 = 1순위 문제).

## 할 일
1. **자료원 순서**
   - 먼저 Relay에 이미 쌓인 숨고 요청 기록(서버 데이터 파일·로컬 API, 읽기 전용)에서 찾는다. 어느 파일/경로를 읽었는지 적는다.
   - 부족하면 준희 크롬에 **새 탭 하나만** 열어 숨고 "받은 요청" **목록 화면**만 읽는다. 아직 안 연 요청은 새로 열지 않는다(읽음 표시가 바뀌면 Codex 응대에 영향). Codex가 쓰는 숨고 탭은 건드리지 않는다. 다 보면 그 탭만 닫는다.
2. 기간: 볼 수 있는 가장 오래된 것부터 오늘까지(최대 60일). 실제 기간을 적는다.
3. docs/soomgo/video-edit-demand-20260924.md 작성:
   - **전체 요청 수를 분야별로**: 영상편집 / 자막 / 문서 / PPT / 기타 — "압도적"이 맞는지 숫자로
   - **영상편집 요청만 한 줄씩 표**(개인정보 없이): 날짜, 편집 종류(컷편집·자막 넣기·유튜브 편집·쇼츠·행사/웨딩·광고/홍보·모션그래픽·기타), 용도, 영상 길이, 원본 개수, 원하는 납기, 고객이 적은 예산(있으면), 추가 요구(썸네일·음악·색보정 등), 요청 핵심 20자 이내
   - **우리 쪽 대응**: 그 요청에 Relay가 견적을 만들었는지·보냈는지, 만들었다면 어떤 서비스·금액으로 — 영상편집을 자막 등으로 잘못 본 건수 따로
   - **묶음 요약**: 종류별 건수, 예산 구간(3만 미만 / 3~10만 / 10만 이상 / 안 적음), 납기 구간, "말하는 영상 컷편집+자막" 범위에 들어가는 건수
   - 감독 참고: 현재 도구(자막 싱크·MP4 입히기)로 바로 할 수 있어 보이는 것 / 새 도구·기술 필요 / 못 하는 것 — 각각 건수 [추정 표시]

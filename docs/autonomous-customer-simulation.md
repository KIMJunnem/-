# Relay Desk 자율 고객응대 시뮬레이션

기준일: 2026-09-26

## 목적

실제 고객이 없는 시간에도 Relay Desk가 합성 고객으로 현재 응대 로직을 반복 검증한다.

핵심 원칙은 **연습은 자동, 운영 변경은 자동 아님**이다.

- 합성 고객 생성: 자동
- 응대 라우팅/가격/상태/안전장치 검사: 자동
- 실패·사람다움 경고 축적: 자동
- 상위 모델 검토 후보 큐 생성: 자동
- 유료 모델 호출: 금지
- 고객에게 실제 발송: 금지
- 규칙/프롬프트/코드 자동 수정: 금지
- 합성 사례를 실제 성공사례처럼 Learning Store에 승격: 금지

## 실행 주기

기본 정책:

- 서버 시작 후 마지막 실행이 오래됐으면 20초 뒤 1회
- 이후 15분마다 실행 시각을 확인
- 실제 시뮬레이션은 180분(3시간)마다
- 1회 합성 고객 80건
- 최근 실행 30회 보관
- 학습 후보 최대 200개

운영정책:

`server/config/astra-relay-operating-policy.json -> customerSimulation`

## 현재 고객 유형

기본 시나리오와 문장 변형을 섞어 반복한다.

- 일반 가격 문의
- 견적 후 진행 의사
- 짧은 확인 답장
- 가격 흥정
- 긴급 납기
- 중간 조건 변경
- 화난 고객/반복 설명
- 환불
- AI 사용 질문
- 파일 즉시 전달 요구
- 범위 밖 업무
- 숨고 시스템 알림
- 보안/내부자료
- 통화 없는 진행
- 쇼츠/릴스 가격
- 결제했다고 주장
- 납품 완료 확인
- 납품 후 수정 요청

매 실행마다 접두어/말끝/줄바꿈/구어체/추가 설명을 변형하여 정확히 같은 문장만 반복하지 않는다.

## 검사

### 하드 실패

예:

- 시스템 알림에 답장
- 진행 의사를 고용 요청으로 못 인식
- 수정 요청을 거래 완료로 오인
- 고위험 요청을 즉시 자동 발송
- 정상 질문을 조용히 버림
- 결제 주장인데 확인 플래그 없음
- 응답 검증기가 틀린 금액/보장 문구/계좌 문구를 통과시킴
- 시뮬레이션 자체 예외

하드 실패가 있으면 `/api/alerts`에도 경고가 올라간다.

### 사람다움 경고

현재 휴리스틱:

- 180자 초과
- 4줄 초과
- 질문 2개 초과
- 느낌표 과다
- "최선을 다하겠습니다", "고객님의 소중한", "전문가가", "퀄리티 보장", 반복적인 "문의 주신..." 등
- 같은 문장 반복

이 경고는 자동으로 운영 프롬프트를 바꾸지 않는다.

## Learning Candidate

새로운 실패/경고는 다음 키로 중복 제거되어 누적된다.

- severity
- issue code
- 고객 archetype
- reply template

각 후보는 최대 3개 예시와 firstSeen/lastSeen/count를 가진다.

중요: **실제 고객 사례 또는 독립 회귀 테스트에서 재현되기 전에는 운영 규칙으로 자동 승격하지 않는다.**

이 규칙으로 합성 데이터 오염을 막는다.

## 교수 모델 연결 준비

정책에 이미 다음 슬롯이 있다.

```json
{
  "teacherReview": {
    "enabled": false,
    "mode": "failures_only",
    "provider": "Claude",
    "model": "claude-opus-5-5",
    "maxCasesPerRun": 5
  }
}
```

지금은 실패 사례를 `teacherQueue`에만 넣고 **실제 Claude/OpenAI 호출은 하지 않는다.**

향후 지속형 에이전트나 유휴시간 에이전트가 공식 제공되면:

1. 하드 실패만 최대 N건 인수
2. 원인 분석
3. 수정 후보 제안
4. 별도 회귀 테스트 생성
5. 기존 전체 테스트 통과
6. 실제 고객 사례와 충돌 없는지 확인
7. 승인된 변경만 운영 반영

순서로 연결한다.

## 로컬 API

상태:

`GET /api/customer-simulation`

전체 기록 포함:

`GET /api/customer-simulation?full=1`

수동 즉시 실행:

`POST /api/customer-simulation/run`

세 경로 모두 로컬 writer 서버에서만 허용한다.

## 저장 파일

Git에 올라가지 않는 운영 데이터:

- `server/data/customer-simulation-state.json`
- `server/data/customer-simulation-latest.txt`

실제 고객 개인정보는 넣지 않는다. 합성 대화 ID는 `SIM-...` 형식이다.

## 비용

현재 자율 시뮬레이션 자체의 유료 AI 비용은 0원이다.

`paidModelCalls=false`와 `autoPatch=false`는 설정값을 true로 써도 시뮬레이터 코드에서 강제로 false로 정규화한다.

즉 잘못된 설정만으로 밤새 API 비용이 발생하거나 코드가 스스로 바뀌지 않는다.

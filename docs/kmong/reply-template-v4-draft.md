## 공통 골격 (A·B·C-1·C-2 모두 같음)
```
문의 주셔서 감사합니다. 보내주신 내용 확인했습니다.
견적 {금액}원 · {납기}에 납품 · 수정 {수정횟수}회 포함
결제는 크몽 안전결제라, 받아보시고 확인하신 뒤에 구매확정하시면 됩니다.
{질문 1개}
```
- {금액}: 서버가 services/*.json(kmong 채널)으로 계산한 값 하나. 계산이 안 되면(null) 견적 줄을 빼고 질문만 보낸다.
- {납기}: 자막 = `당일~1일` / 문서 = 5쪽 이하 `당일~1일`, 6~15쪽 `1~2일`, 16쪽 이상 `2~3일`
- {수정횟수}: 자막 2 (`subtitle.json` includedRevisions), 문서 3 (`document_writing.json` includedRevisions)
- 당연한 작업 설명은 넣지 않는다. 문서(C-1·C-2)의 받아쓰기·"자료에 없는 사실은 넣지 않는다" 설명은 뺀다.
- 자막 A·B의 싱크 설명 문장과 무료 샘플 문장은 되살린다(아래 "되살린 문장").

## 유형별로 다른 것 — 질문 하나뿐
- A 자막(스크립트 있음) / B 자막(스크립트 없음): ① 영상 길이 ② 자막 파일만 필요한지, 영상에 입혀야 하는지
- C-1 타이핑: ① 쪽수 ② 파일 형식(한글/워드) ③ 표·양식을 그대로 살려야 하는지
- C-2 문서 작성: ① 원하는 분량 ② 어디에 쓰는 문서인지 ③ 파일 형식
- 질문은 위 순서로 하나만. 고객이 이미 준 정보는 다시 묻지 않는다.

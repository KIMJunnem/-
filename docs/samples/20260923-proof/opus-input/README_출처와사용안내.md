## 제작과 확인

문서·프레젠테이션 제작 플러그인과 Agentbroko 영상 편집·자막 번역 워크플로를 활용했습니다. 외부 유료 생성 API는 호출하지 않았습니다.

자막 12개에 대해 시간 순서, 시간 겹침, 최소 노출 시간, 최대 두 줄, 한 줄 길이와 읽기 속도를 확인했습니다. 타이밍은 사용한 영상 사본에 대응하는 공개 자막 기준입니다. 음성 전사 모델을 이용한 독립 싱크 검증은 수행하지 않았습니다.

보고서 5쪽과 슬라이드 9장의 렌더링을 확인했습니다. PPTX 구조·크기·글꼴 검사와 재가져오기 검사를 통과했습니다. PowerPoint 설치 환경에서의 직접 실행 검사는 별도입니다.

이 파일은 공개 포트폴리오로 준비한 결과물입니다. 숨고·크몽 게시나 고객 발송은 수행하지 않았습니다.

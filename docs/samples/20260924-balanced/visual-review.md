# Swan 작업별 샘플 검수 — 2026-09-24

## 범위

신규 PDF 5종(각 2쪽), 기존 전문 보고서 4쪽, 기존 PPT 7장, 기존 자막 영상 5편을 한 목록으로 정리했다. 실제 고객 사례나 매출 실적으로 표시하지 않는다. 가격 및 운영 코드는 변경하지 않았다. 유료 API 호출, 고객 발송, 외부 게시 없음.

## 문서 및 PPT

- Pretendard, MaruBuri, IBM Plex Sans KR의 실제 제목·본문 비교 이미지를 확인하고 Pretendard를 선택했다.
- 신규 PDF 10쪽을 이미지로 열어 직접 확인했다. 제목, 강조, 표, 워터마크, 페이지 끝의 넘침을 확인했다.
- 표의 어절 단위 줄바꿈을 보정한 후 일반 글 2쪽, 교정 2쪽, 대본 1쪽을 다시 확인했다.
- 신규 PDF는 ReportLab으로 작성하고 Poppler로 렌더했다. 신규 DOCX는 작성용 원본이며 렌더 검증을 완료하지 않아 배포 ZIP과 목록에서 제외했다.
- 재사용 보고서와 PPT는 기존 최종 검수본을 복사하고 해시를 대조했다. 이번에는 전체 페이지·슬라이드 모음 이미지로 다시 확인했다. 기존 개별 페이지 검수 기록은 ../20260923-professional/visual-review.md에 있다.
- 보고서의 운영 수치는 가상 계산이다. 녹취 샘플은 공개 인터뷰의 편집 자막을 이용한 읽기용 기록이며, 축어 녹취·인증 녹취록이 아니다.

## 자막 영상

- 한국어·프랑스어·일본어·중국어 지역어 60초 영상과 영어 비교 21초 영상을 기존 파일 그대로 정리했다.
- FFmpeg 전체 디코딩, SRT 시간 순서·겹침·영상 길이 내 종료를 검사했다.
- 모든 자막 블록의 중앙 프레임과 처음·끝을 추출한 5개 모음 이미지를 직접 확인했다. 자막 잘림과 화면 밖 넘침은 발견하지 못했다.
- 기존 파형 정렬 및 독립 전사 검수 기록을 보존했다. 이번에 음성을 처음부터 끝까지 듣는 검수와 모바일 재생 확인을 새로 완료한 것은 아니다.
- 따라서 영상은 review_copy이며, 동기화 최종 확인 전 고객 자동 발송 대상으로 사용하지 않는다.
- 중국어 영상은 허난 지역어 자료다. 표준중국어 샘플이라고 소개하지 않는다.
- CC BY-SA 4.0 영상·파생 기록과 CC BY 3.0 영어 영상의 출처, 편집 표시, 라이선스 안내를 묶음에 포함했다.

## 사용 방식

ready/index.html에서 종목별로 확인한다. 요청에 맞는 샘플 1개를 먼저 선택한다. 문서 편집 샘플을 인포그래픽 전문 디자인의 실적으로 소개하지 않는다. 대본은 작업 범위를 확인한 뒤 별도 견적한다. 자소서·이력서 샘플은 포함하지 않는다. 로컬 파일 경로는 외부 공개 링크가 아니다.
